## 目录约定

```
Self-Done/
├── README.md                              # 仓库总览（本文件）
└── <项目名>/                              # 一个项目一个文件夹
    ├── README.md                          # 项目说明：目标、引脚、烧录配置、踩坑记录
    ├── firmware/                          # 固件源码
    ├── hardware/                          # 硬件工程（EasyEDA / 立创EDA 等）
    └── docs/                              # 规格书、设计报告、项目总结
```

新增项目时：在根目录建同名文件夹，按上述结构放入 `firmware/`、`hardware/`、`docs/` 和项目 README，然后在上方「项目列表」中登记一行。
