3.2 发现的问题（分级）

P0 致命 SD 卡时钟串阻 R8 = 300kΩ —— 卡完全无法工作

V20 中 R8 = RL0805A300K（300kΩ）串在 SD 的 CLK 线上。时钟信号经 300kΩ 串阻后边沿完全被破坏（RC 时间常数过大），SD 卡根本无法初始化，TF 视频播放整条链路报废。

修正：改为 22Ω（V21 已改）。SD CLK 为推挽输出，串阻仅用于抑制过冲/EMI，典型 22~33Ω。

P0 功能缺失 缺「电脑开机亮屏 / 关机熄屏」硬件电路

V20 只有一个背光 MOS（Q1 P-MOS），没有任何「检测电脑是否开机」的输入。需求「电脑开机屏幕点亮、关机屏幕熄灭」在 V20 完全没有硬件支撑。

修正：V21 新增 Q2（AO3400A N-MOS）+ J1（机箱 5V），与 Q1 串联构成「双 MOS 背光互锁」——只有 Q1(PWM) 和 Q2(开机) 同时导通，屏幕才亮。

P1 重要 背光 P-MOS 高边 + 3.3V 驱动，无法彻底关断

V20 用 AO3401（P 沟道）做高边开关，源极接 5V，栅极由 3.3V GPIO 驱动（经 R12=100Ω，R15=10k 上拉 5V）。GPIO 拉高 3.3V 时 Vgs ≈ −1.7V，仍高于 AO3401 阈值（|Vgs(th)|≈0.7~1.3V），背光关不断、PWM 调光到不了 0%。

修正：V21 改 N-MOS 低边（AO3400A，3.3V 栅极即可完全饱和导通/关断），并串联 Q2 互锁。

P1 重要 SD 卡检测脚接 IO45（Strapping 引脚）

V20 将卡检测 DET-SW 接到 IO45。IO45 是 ESP32-S3 的启动 strapping 脚（决定 VDD_SPI 电压），上电瞬间该脚电平若被卡检测开关/上拉改变，可能导致随机启动失败。

修正：V21 把卡检测改到 IO38（普通 GPIO），IO45 不再使用。

P2 建议 3.3V 用 LDO（HR1117V-3.3），发热大、效率低

V20 用 1117 LDO 把 5V 降到 3.3V。满负载（主控+PSRAM+屏+卡）约 350~450mA，LDO 损耗 (5−3.3)×0.4 ≈ 0.7W，SOT-223 温升约 40℃+，且效率仅 ~66%。

建议：V21 改 TLV62569 同步 Buck（效率 ~90%+，几乎不发热）。若坚持极致省成本，LDO 也能用，但需加强散热、接受发热。

P2 建议 背光限流 27Ω 偏临界

V20 R3=27Ω：背光电流 ≈ (5−3.0)/27 ≈ 74mA，已逼近规格书 80mA 上限；且 4 颗 LED 并联，裕量不足。

建议：V21 改 36Ω，电流 ≈56mA，亮度足够（屏幕标称 350~400cd/m²@80mA，56mA 仍很亮）且寿命更稳。

4.1 背光互锁电路（核心新增）

J1 接线说明：「机箱 5V」取电脑电源的 SATA 供电头 / 大4P Molex 的 +5V 线（这些供电只在电脑开机时才有 5V），或主板 USB 2.0 排针的 +5V。若该 USB 口关机后仍带电（Always-On 充电口），则请改用 SATA/Molex 的 5V。若整板仅由关机即断电的 USB 供电，也可简化——但保留 Q2 更稳健。

5.1 屏端写带宽（8080 并口 8bit）

ST7789P3 8080 接口最小写周期 ≈66ns → 最高约 15MHz。V21 按 12MHz 设计（留裕量）：

8bit × 12MHz = 12 MB/s；单帧 153KB → 写一帧 ≈ 12.8ms → 理论上限 ≈78fps ✓

5.2 卡端读带宽（SD 4-bit）

SDMMC 4-bit @25MHz 理论峰值 12.5MB/s，实际 70~85% ≈ 9~10MB/s，刚好覆盖 60fps 原始帧流。若视频按 MJPEG/自定义帧内压缩 存储，SD 读取压力大幅下降，60fps 更加从容。

5.3 结论

硬件层面 60fps 成立。真正的瓶颈在固件（JPEG 软解 + SD 读 + 并口写 的流水线），不在硬件。V21 的 8bit 并口 + 4-bit SD + 2MB PSRAM 组合是 ESP32-S3 上能达到该指标的合理方案（比 SPI 屏快一个数量级）。
提示：2MB PSRAM 可容纳多帧缓存 + 解码缓冲，建议用 DMA 走 8080 写屏（ESP32-S3 有 LCD_CAM 外设，但本设计为纯 GPIO 并口，靠 GPIO 矩阵 + DMA 即可）。
