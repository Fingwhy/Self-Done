# 整体设计方案

日期：2026-11-26。阶段：架构规划；本文参数均为目标或选型依据，不是制造说明。

## 1. 确定需求与待定建议

已确定：前面 2 个普通 USB-A、1 个隔离 USB-A、1 个隔离 Type-C，背面 1 个连接电脑的 Type-C；不需要给电脑充电；用于日常外设、开发板下载和调试。

建议但尚未确认：外置 5V/4A 电源及额外 DC 电源座、一块主板加两块隔离小板、普通口 900mA 和隔离口 500mA 的供电目标。电脑端口能力、目标调试器、预算和外壳尺寸尚待确认。

## 2. Hub 与数据通路

- 核心候选 CH634X，参考 Raintek 项目和沁恒 CH634DS1/评估板资料。
- 两路下行同时布置 USB 3.0 与 USB 2.0 至普通 USB-A。
- 另外两路仅将 USB 2.0 D+/D− 引入各自 ADuM3165，未用 SuperSpeed 引脚按手册处理。
- 上行 Type-C 的正反插沿用经过核对的原生方案；先确认交换上下行模式下的实际引脚和端口分配。
- 两个 ADuM3165 使用各自时钟及去耦，参考官方主机端隔离应用；不将 3165 与 3166 的时钟侧混用。
- Hub 外设电源与端口启用/故障逻辑要匹配实际结构。隔离后的使能或故障反馈若跨屏障，必须经额外隔离器件，不能直接拉线跨接。

## 3. 隔离端口

USB-A 支路：Hub D+/D− → ADuM3165 → 设备侧低电容 ESD → USB-A。设备端 VBUS 来自该支路隔离电源，经稳压、限流和反向阻断后输出。

Type-C 支路使用同样的隔离通路，另外配置完全位于设备侧的 DFP/Source CC 控制。控制器要支持连接检测、默认 USB 电流声明、VBUS 开关及放电；具体型号尚未确定。USB 2.0 两组同名数据触点按规范连接，不布置 SuperSpeed 通路。

Type-C 电流声明不得高于实际供电能力；5V/500mA 目标下不声明 1.5A/3A，也不使用仅适合受电端的 CC 下拉冒充下行口。C-to-C 正反插均须实测。

## 4. 电源预算与路径

| 项目 | 初步预算 |
|---|---|
| 两个普通 USB-A | 2 × 5V × 0.9A = 9W |
| 两个隔离端口的有效输出 | 2 × 5V × 0.5A = 5W |
| 隔离转换及隔离芯片设备侧 | 按候选方案效率与最大消耗核算，不能忽略 |
| Hub、时钟、保护、指示及余量 | 单独列入最终预算 |
| 外置电源候选 | 稳压 5V/4A，20W；定型前核算最坏条件 |

每路隔离电源初选约 4～5W 能力，输出稳压到 USB 允许范围；实际按空载过压、满载压降、启动、短路和温升选型。候选为有足够持续功率的隔离 DC-DC 模块，或参考 SN6505＋变压器＋整流稳压；尚未选定料号。两路输出不得并联或共地。

外置电源 → 输入反接/过压/过流保护 → 主 5V → 普通口独立电源开关，以及两套隔离转换器。隔离口在设备侧分别限流并防反向供电。各保护器件需按实际电压、电流和故障能量选型，普通 ESD 管不能自动承担持续 24V 误接。

上行 VBUS 用于主机连接检测；外部主电源不得倒灌电脑，拔除上行线后需正确处理 Hub 连接。默认按自供电模式设计；首版不承诺无外接电源的完整工作模式。若加入电脑供电备选，须重新核对 Type-C 电流检测、输入选择和端口功率分配。

## 5. 三个地与保护边界

| 电气域 | 包含电路 |
|---|---|
| GND_MAIN | 电脑侧、CH634X、两个普通口、隔离器主机侧及转换器输入侧 |
| GND_ISO_A | 隔离 A 口的隔离器设备侧、电源输出和保护 |
| GND_ISO_C | 隔离 C 口的隔离器设备侧、电源输出、CC 和保护 |

区域之间只能通过设计规定的隔离元件耦合。接口屏蔽壳、固定孔、金属面板、散热片、指示灯和调试排针均需检查，不能造成意外导通。跨屏障电容如确需加入，必须单独评估漏电、耐压与 EMI，不能随意搭接。

隔离小板设备侧的测量不得用电脑共地仪器意外跨接屏障。实验板同时连接普通 USB、其他非隔离电脑接口或接地仪器，也可能绕过隔离。隔离不是恶意 USB 软件行为过滤，也不能保护设备侧调试器的所有信号引脚。

## 6. PCB 与结构

主板建议四层：高速信号层邻近连续参考地，使用板厂实际叠层计算 USB 差分阻抗，目标依官方指南核定。接口保护靠近连接器，避免长支路和不必要过孔；不能直接照搬别人的线宽间距。

两块隔离小板分别布置隔离屏障及禁止铺铜区，按目标隔离等级和器件资料确定间距，必要时开槽。板间仅连接隔离前的电源和 USB 2.0 信号，连接器与短线作为通道的一部分校核。

外壳优先塑料 3D 打印，普通口与隔离口清晰标注。前四口、背面上行 Type-C 和候选 DC 座，预留隔离电源及芯片散热空间。接口间距、板卡定位、螺丝长度和外壳尺寸在 PCB 定位后确定。
