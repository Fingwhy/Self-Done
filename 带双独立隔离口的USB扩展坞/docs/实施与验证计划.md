# 实施与验证计划

日期：2026-11-26。以下测试均未执行；后续在本目录保存实际记录，不将计划勾选成通过结果。

## 1. 定型前待确认

- [ ] 电脑型号、Type-C 的 USB 速度与供电能力。
- [ ] 实际常用设备型号：ESP32 开发板、ST-Link/DAP、USB-CAN、串口适配器等，列出同时使用场景。
- [ ] 是否接受额外 DC 电源座和外置 5V/4A 电源。
- [ ] 两个隔离口各 500mA 是否覆盖设备峰值；目标板自供电时的回灌路径。
- [ ] 预算、接口间距、外壳体积、板间连接和装配方式。

## 2. 设计阶段

- [ ] 核对并记录上游版本及许可，取得工程源文件。
- [ ] 根据 CH634X 实际模式确认四个下行端口及全部电源/检测引脚。
- [ ] 完成原理图分块、最坏情况电源预算、热预算和候选 BOM。
- [ ] 选定 Type-C 下行 CC 控制、端口限流、反向阻断和隔离电源。
- [ ] 审查三个电气域，检查使能/故障信号及屏蔽壳是否跨接隔离。
- [ ] 完成 ERC、PCB DRC、阻抗/叠层、机械和制造资料核对。

## 3. 隔离板验证

先使用限流实验电源；数据接入优先用独立测试主机或可替换测试 Hub，基础电源检查通过后再接日常电脑。

- [ ] 断电检查 GND_MAIN、GND_ISO_A、GND_ISO_C 及接口壳的意外直流连接。万用表不导通只检查连线，不证明额定隔离耐压。
- [ ] 先测电源空载、启动、关闭和阶跃负载，确认无过压、振荡或重启。
- [ ] 分别测试 100mA、250mA、500mA 输出、电压、纹波和温升；条件与仪器写入记录。
- [ ] 用受控电子负载检查限流及故障恢复，不直接将高压接入 USB 来验证保护。
- [ ] 验证目标板自供电时无异常回灌，测试外部供电断开/重接。
- [ ] 检查隔离芯片枚举、USB 复位和重复热插拔。

## 4. Hub 及整机验证

- [ ] 上行 Type-C 两种方向均完成 USB 2.0 和 USB 3.0 枚举。
- [ ] 两个普通口分别及同时传输，记录实际链路速度、共享带宽与错误情况。
- [ ] 设备侧 Type-C 使用 C-to-C 两种方向和常用数据线测试，确认插入/拔出、VBUS 和 CC 行为。
- [ ] 两个隔离口同时执行下载/日志任务，普通口并行接日常外设，检查掉线和相互影响。
- [ ] 按实际设备逐项测试下载、校验、日志、复位、下载模式切换和重枚举，不用 U 盘测试替代调试器测试。
- [ ] 测试电脑睡眠/唤醒、上行线拔插和外部电源断电/重接；确认不会给电脑倒灌。
- [ ] 按目标负载连续运行并记录隔离芯片、隔离电源、连接器和壳内温升。
- [ ] 装壳后重新检查隔离区是否被螺丝、接口壳或其他结构跨接。

## 5. 结果记录格式

每项记录：日期、硬件版本、固件/配置版本、测试电脑与系统、设备及线材型号、供电条件、仪器、负载、测量值、日志/照片、通过判据及结论。保护能力只按实际已验证条件描述；不依据隔离芯片标称值宣称整机高压安全认证。
