# 带双独立隔离口的 USB 扩展坞

**项目状态：方案规划，尚未制作或验证硬件。**  
建档日期：2026-11-26

制作一个兼顾日常 USB 扩展和开发板烧录调试的桌面扩展坞。前面有两个普通 USB-A、一个隔离 USB-A、一个隔离 Type-C；背面通过可拆卸 Type-C 数据线连接电脑。不需要给电脑充电。

参考开源方案，自行完成电路整合、PCB、外壳和测试。当前仅提交方案文档，没有可直接下单制造的工程、Gerber 或 BOM。

## 接口目标

| 位置 | 接口 | 功能目标 | 单口供电目标 |
|---|---|---|---|
| 前面 | 普通 USB-A ×2 | USB 3.0，最高 5Gbps | 每口 5V/900mA |
| 前面 | 隔离 USB-A ×1 | USB 2.0，最高 480Mbps，烧录及调试 | 5V/500mA |
| 前面 | 隔离 Type-C ×1 | USB 2.0，最高 480Mbps，支持正反插，烧录及调试 | 5V/500mA |
| 背面 | 上行 Type-C ×1 | 连接电脑，USB 3.0 | 不向电脑充电 |

速率为接口目标，所有设备共享上行链路；供电目标以外接电源方案为前提，均待测试。隔离 Type-C 不提供视频、USB 3.x 或 PD 高压输出。隔离保护电脑的电气连接，不提供 USB 内容过滤或恶意代码防护。

## 拟定结构

```text
电脑 ─ 背面 Type-C ─ CH634X 四口 Hub
                       ├─ 普通 USB-A ①
                       ├─ 普通 USB-A ②
                       ├─ ADuM3165 ①＋独立隔离电源① ─ 隔离 USB-A
                       └─ ADuM3165 ②＋独立隔离电源② ─ 隔离 Type-C
                                                    ＋隔离侧 CC 控制
```

两路隔离端口各用一颗数据隔离器和一套隔离电源。主板地、隔离 A 口地、隔离 C 口地分别独立；不是一颗隔离器后面再分成两个共地端口。

首版建议一块四层主板加两块隔离小板，使用嘉立创 EDA 专业版整合，功能验证后用 SolidWorks 设计打印外壳。基础数据通路无需自行编写 MCU 固件，但 Hub 模式及配置仍需核对。

## 供电决策

建议采用外置稳压 5V/4A 电源，背面另加 DC 电源座：**五个 USB 接口，另有一个电源接口**。这是待确认的结构建议，不属于已定案的五个 USB 接口需求。若要求严格只有五个物理接口，需要重新评估供电方式并降低或动态分配输出功率。

外接电源供应 Hub 和外设，不给电脑充电。电脑 VBUS 的检测、自供电 Hub 配置以及防倒灌必须单独设计。不能假设任意电脑 Type-C 都能供应四口满载。

## 使用边界与许可

隔离和过流保护降低故障传播风险，不能保证实验板误接 24V 后扩展坞、调试器或电脑均不损坏。器件的隔离耐压不等于整机安全认证，本项目不将其作为市电或高压人身安全隔离设备。
