# 硬件工程

当前尚无原理图、PCB、BOM 或制造文件。本目录不是可下单打样的工程包。

计划采用嘉立创 EDA 专业版，一块 CH634X 主板和两块独立 ADuM3165 隔离小板。Type-C 隔离板增加本地 CC 控制；两块小板各自配置隔离电源和端口保护。

后续资料按硬件版本保存：

- 原生工程和原理图 PDF；
- 带确切料号、封装、来源和许可记录的 BOM；
- PCB 叠层、阻抗与隔离间距说明；
- ERC/DRC 及审查记录；
- Gerber、钻孔、贴片坐标和装配说明；
- 对应版本的实测记录与修改清单。

外壳 STEP/STL 和 SolidWorks 工程待 PCB 安装尺寸确定后加入项目。基础架构不包含自研 MCU 固件，因此当前不创建空 firmware 目录；若后续引入控制器固件，再单独建档。
