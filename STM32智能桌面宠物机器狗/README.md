# STM32 智能桌面宠物（机器狗）

一只放在桌上的四足小机器狗：**STM32F103C8T6 + 5 路舵机 + 0.96" OLED + 离线语音 + 蓝牙**。听得懂人话，也会被手机遥控，能立正、前进、后退、左右转、摇尾巴、趴下、蹲下、睡觉、往前跳、打招呼、伸懒腰。

这是我从"跟着教程点亮一个舵机"开始，一路做到四版电路板的第一个完整嵌入式项目。

## 项目概览

| 项目 | 内容 |
|---|---|
| 主控 | STM32F103C8T6 最小系统板（四个硬件版本都是开发板方案） |
| 执行机构 | 5 路舵机 PWM：左前 / 右前 / 左后 / 右后 四足 + 尾巴 |
| 显示 | 0.96" OLED，I2C，江协科技例程字库，表情可自定义 |
| 语音 | 机芯智能 SU-03T1 / CI-03T，USART1，唤醒词与命令词在智能公元配置 |
| 无线 | 串口透传蓝牙模块，USART3（V1.2.1 换成体积更小的低功耗型号） |
| 电源 | 3.7V 锂电池 + 5V 充放电模块 → 舵机 5V / 板载 3.3V |
| 烧录 | CH340 串口 ISP；V1.1 起做了语音与主控共用的烧录口 |
| 结构 | SolidWorks 建模，3D 打印 |
| PCB | 嘉立创 EDA，2 层，四个版本（V1.0 / V1.1 / V1.2 / V1.2.1） |
| 开发周期 | 2024-12 ~ 2025-08 |

## 实现的功能

- ✅ **四足动作**：立正、前进、后退、左转、右转、趴下、蹲下、向前跳
- ✅ **情绪动作**：摇尾巴、睡觉、打招呼、伸懒腰
- ✅ **语音控制**：SU-03T1 / CI-03T 离线识别，识别到命令词后从 USART1 发指令码
- ✅ **蓝牙控制**：手机串口助手 / 小程序发同名指令码，走 USART3
- ✅ **OLED 表情**：随状态切换（待机、执行、睡眠），字库与图形可自行取模
- ✅ **四角呼吸灯**：板子四角各一颗，可开可关，待机时更有"活着"的感觉
- ✅ **电量检测**：V1.2.1 加入，ADC 采样分压后判断剩余电量
- ✅ **舵机通道可换**：语音模块两代串口通道不同（B0/B1 与 PB5/PB6），板上丝印标清楚了
- ⏳ **贴片一体板**：替换开发板方案，缩小体积、理顺供电（计划中）
- ⏳ **平滑步态**：当前是关键帧直出，还没做加减速插值

## 硬件版本

| 版本 | 时间 | 主要变化 |
|---|---|---|
| V1.0 | 2024-12-02 | 首版。3.7V 锂电 + 5V 充放电模块 + AMS1117-3.3，五路舵机排针直出，问题较多 |
| V1.1 | 2025-02-19 | 去掉 AMS1117（最小系统板自带 LDO），语音模块改排母直插，四角呼吸灯，共用烧录口 |
| V1.2 | 2025-03-11 | 重新布局，同时兼容 SU-03T1 与 CI-03T，丝印标全 |
| V1.2.1 | 2025-08-20 | 加电量检测，换小体积蓝牙模块，TX/RX 丝印统一为交叉标注 |

## 下一步

1. 贴片一体板：MCU 直接上板，删掉多余的稳压与杜邦线，把板子塞进结构内部
2. 舵机独立供电：现在五路同时动作会拉垮 5V，改用大电流 buck + 独立储能电容
3. 步态平滑：关键帧之间做缓动插值，走起来别像抽搐
4. 电流采样：加一路采样电阻，做堵转与落地检测
