# 硬件工程说明

## 一、工程文件在哪

原始 EDA 工程（原理图 + PCB）、SolidWorks 结构模型、语音固件与 BOM 都比较大，没有放进仓库，在开源工程页与网盘资料里：

- 立创开源工程：<https://oshwhub.com/sngelswyh/stm32-smart-desktop-pet>
- 资料网盘链接在工程页最下方（按版本分开：V1.0 / V1.1 / V1.2.0 / V1.2.1）

**取资料时注意版本对应**：板子是哪一版，就下哪一版的资料。四个版本的电源与语音接口都不一样，混用会出问题。

## 二、板卡参数

| 项 | 内容 |
|---|---|
| 层数 | 2 层 |
| EDA | 嘉立创 EDA 专业版 |
| 主控 | STM32F103C8T6 最小系统板（排母直插） |
| 舵机接口 | 5 组 3P 排针（5V / GND / PWM） |
| 语音接口 | 排母，兼容 SU-03T1 与 CI-03T |
| 蓝牙接口 | 4P 排母（VCC / GND / TX / RX） |
| 显示接口 | OLED 排母（I2C） |
| 电池接口 | 2.0mm 间距端子 |
| 充电 | 板上焊充放电模块 |
| 指示 | 四角呼吸灯 ×4 + 电源灯 |
| 采样 | 电池分压 → ADC（V1.2.1） |

## 三、版本对照

| 版本 | 3.3V 来源 | 语音 | 蓝牙 | 特殊 |
|---|---|---|---|---|
| V1.0 | 板载 AMS1117 | SU-03T1（B6/B7） | 4P 排母 | 烧录需拔模块 |
| V1.1 | 最小系统板 LDO | SU-03T1（B0/B1） | 4P 排母 | 呼吸灯、共用烧录口 |
| V1.2 | 最小系统板 LDO | SU-03T1 + CI-03T | 4P 排母 | 重新布局、丝印补全 |
| V1.2.1 | 最小系统板 LDO | 同上 | 小体积低功耗模块 | 电量检测、丝印交叉标注 |

## 四、焊接顺序建议

1. 先焊最矮的：电阻、电容、二极管
2. 再焊端子与排母（锂电端子、充放电模块焊盘）
3. 最后焊排母，焊之前先插上模块比对高度，避免歪
4. 焊完先量 5V 与 3.3V 对地阻值，确认没有短路再上电
5. 上电后先测电压，再插舵机、再插 MCU
