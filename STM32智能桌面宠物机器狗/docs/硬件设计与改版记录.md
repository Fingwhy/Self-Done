# 硬件设计与改版记录

> 板卡：STM32 智能桌面宠物驱动底板（四足 + 尾巴）
> EDA：嘉立创 EDA 专业版，2 层板
> 版本：V1.0 → V1.1 → V1.2 → V1.2.1

## 一、电路分块

| 分区 | 内容 | 设计要点 |
|---|---|---|
| 电源 | 锂电端子、充放电模块焊盘、3.3V 稳压 | 5V 与 3.3V 分离布线，舵机 5V 走宽铜 |
| 舵机接口 | 五组 3P 排针（5V / GND / PWM） | 成组排列在板侧，方便插拔与绑线 |
| 主控 | C8T6 最小系统板排母 | 双排母直插，留出 USB 与复位按键的避让 |
| 显示 | OLED 排母 | 板边引出，屏幕可以立在头顶 |
| 语音 | SU-03T1 / CI-03T 排母 | 与烧录口并线，丝印标复用脚 |
| 蓝牙 | 4P 排母（VCC/GND/TX/RX） | V1.2.1 换小体积模块，位置内移 |
| 指示 | 四角呼吸灯 ×4 | 可关，待机呼吸 |
| 采样 | 电池分压 → ADC | V1.2.1 新增 |

## 二、版本改动与原因

### V1.0（2024-12-02）· 首版

- 3.7V 锂电 + 5V 充放电模块，板载 **AMS1117-3.3** 给 MCU
- 五路舵机 PWM 从左侧上下两排 5V 排针引出：PA0 左前、PA1 右前、PA2 左后、PA3 右后、PA6 尾巴
- OLED 接最左侧中间排母；语音接右上角排母（USART1）；蓝牙接右下角排母（USART3）
- 烧录需要单独接线，且要拔掉语音模块

**问题**：板上稳压与最小系统板重复；烧录麻烦；布局零散，飞线多。

### V1.1（2025-02-19）· 收敛

| 改动 | 原因 |
|---|---|
| 删除 AMS1117 | C8T6 最小系统板内部已有 3.3V LDO，重复降压白占板面还多一路压差损耗 |
| 语音模块改排母直插 | 买带排针的模块直接插，省掉杜邦线，也避免插错位置 |
| 锂电改 2.0mm 间距端子 | 电池直接插，不用焊；充放电模块仍焊在板上 |
| 四角加呼吸灯 | 待机时有生命感，可关 |
| 增加共用烧录口 | 语音与主控下载线并到一个排针，烧录不拆线 |
| 走线重排 | 线束贴边走，减少与舵机臂干涉 |

### V1.2（2025-03-11）· 兼容两代语音模块

- 重新布局，电源与信号彻底分区
- **同时兼容 SU-03T1 与 CI-03T**：两者串口复用脚不同（SU-03T1 用 B0/B1，CI-03T 用 PB5/PB6），板上把两组都留出来
- 丝印层补全，按丝印焊即可，不用对着原理图数脚

### V1.2.1（2025-08-20）· 最终版

| 改动 | 原因 |
|---|---|
| 增加电量检测 | 之前不知道剩多少电，玩到一半直接断电重启 |
| 换小体积低功耗蓝牙模块 | 原模块体积大，装进结构后顶到腿；新模块正常状态指示灯一闪一闪 |
| TX/RX 丝印统一为交叉标注 | 之前丝印按"模块视角"标，插的时候总要反着想一遍，容易接反 |
| 原理图 / PCB 一致性修正（2025-11-07） | 早期有几个元件是直接在 PCB 里复制的，原理图没有，导致转图报错 |

## 三、已知缺陷

| 编号 | 问题 | 影响 | 改进方向 |
|---|---|---|---|
| P1 | 充放电模块输出电流不足 | 四路舵机同时动作 → 5V 跌落 → MCU 复位、语音重启 | 舵机独立 5V/3A buck，MCU 单独 LDO，单点共地 |
| P2 | 开发板方案占板面 | 结构内部空间紧张，杜邦线易被舵机臂碰到 | 一体板，MCU 直接贴片 |
| P3 | 无舵机电流采样 | 堵转、卡死只能靠听声音判断 | 加采样电阻 + 比较器/ADC |
| P4 | BOM 未规范 | 复刻困难 | 出板即出 BOM，与原理图位号对齐 |
| P5 | 早期原理图与 PCB 不一致 | 转图报错，劝退复刻的人 | 已修，之后一律"原理图先行" |

## 四、如果重画一版

1. **先算电流再画板**：五路 9g 舵机，堵转按单路 0.7A 估，同时动作按 3 路峰值算 → 需要 2A 以上的 5V 供给，留 1.5 倍余量
2. **两路电源彻底分开**：舵机 5V 用 buck（如 MP1584/MP2315 一类），MCU 用低噪声 LDO，地平面单点汇合
3. **每路舵机就近加储能电容**：100µF 起，抑制起动瞬间的电压塌陷
4. **MCU 直接上板**：STM32F103C8T6 贴片 + SWD 排针，省掉整块最小系统板
5. **留调试口**：SWD + UART 双通道，固件出问题时不用拆壳
