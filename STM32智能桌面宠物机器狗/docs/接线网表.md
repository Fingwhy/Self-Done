# 接线网表

> 依据 V1.2.1 板卡与工程文件整理。丝印与本文不一致时，以板上丝印为准。
> 引脚分配自 V1.0 起沿用到最后一版。

## 一、舵机（TIM PWM，50Hz）

| 功能 | MCU 引脚 | 定时器通道 | 板上接口 | 备注 |
|---|---|---|---|---|
| 左前脚 | PA0 | TIM2_CH1 | 左侧 5V 排针区 | 脉宽 0.5~2.5ms ↔ 0~180° |
| 右前脚 | PA1 | TIM2_CH2 | 左侧 5V 排针区 | 同上 |
| 左后脚 | PA2 | TIM2_CH3 | 左侧 5V 排针区 | 同上 |
| 右后脚 | PA3 | TIM2_CH4 | 左侧 5V 排针区 | 同上 |
| 尾巴 | PA6 | TIM3_CH1 | 左侧 5V 排针区 | 走 TIM3，避免和四足抢同一个定时器 |

舵机三线：**棕 = GND，红 = 5V，黄 = PWM 信号**。五路信号线全部单独走，5V 与 GND 在板内汇流后接充放电模块输出。

> 舵机安装方位必须与结构模型一致，装反了动作会左右颠倒、走路原地打转。装配顺序：先中立位（90°）再上舵机臂。

## 二、串口

### USART1 —— 语音模块

| MCU 引脚 | 方向 | 接到语音模块 |
|---|---|---|
| PA9 (USART1_TX) | 出 | 模块 RX |
| PA10 (USART1_RX) | 入 | 模块 TX |
| 3.3V | — | VCC（按模块要求，SU-03T1/CI-03T 均为 3.3V 逻辑） |
| GND | — | GND |

两代语音模块的**串口复用脚不同**，配置智能公元时必须对上：

| 模块 | TX 复用脚 | RX 复用脚 | 备注 |
|---|---|---|---|
| SU-03T1 | **B0** | **B1** | 早期板用 B6/B7，插到 V1.2 及以后的板子要改成 B0/B1 |
| CI-03T | **PB5** | **PB6** | V1.2 起才兼容，功能比 SU-03T1 多 |

### USART3 —— 蓝牙模块

| MCU 引脚 | 方向 | 接到蓝牙模块 |
|---|---|---|
| PB10 (USART3_TX) | 出 | 模块 RX |
| PB11 (USART3_RX) | 入 | 模块 TX |

排母丝印上标的 **TX 是单片机 RX 的复用口**，直接对着丝印插即可（V1.2.1 已把交叉关系写进丝印）。

## 三、OLED

| 信号 | MCU 引脚 | 备注 |
|---|---|---|
| SCL | PB8 | 软件 I2C（江协科技 OLED 例程默认），上拉 4.7k |
| SDA | PB9 | 同上 |
| VCC / GND | 3.3V / GND | 0.96" 128×64，SSD1306 |

OLED 通过排母 + 面包板线连接，方便换屏和拆装。

## 四、电源

| 节点 | 来源 | 去向 |
|---|---|---|
| VBAT | 3.7V 锂电池，2.0mm 间距端子直插 | 充放电模块 BAT 输入 |
| 5V | 充放电模块输出 | 五路舵机 VCC、板内 3.3V 稳压输入 |
| 3.3V | 最小系统板自带 LDO（V1.1 起删掉板上 AMS1117） | MCU、OLED、语音、蓝牙 |
| GND | 共用 | 全域，单点汇流 |

> **注意**：舵机 5V 与 MCU 3.3V 同源。四路同时动作时 5V 跌落会带动 3.3V 塌陷，这是本板最需要改的地方（见「项目总结 · 已知问题」）。

## 五、其他
