# 智能家居魔法系统

**项目状态：准备开始**  
计划日期：2026-11-05

以 ESP32-C3 与 MPU6050 为起点，自主完成一支可识别挥动手势的魔法棒，通过本地网络控制灯和智能插座。

本项目由本人独立完成硬件搭建、固件编写、数据采集、模型训练、家居联动及测试。参考项目用于学习技术路线；当前仅完成方案规划，尚未完成采购、硬件验证或功能实现。

## 第一阶段目标

- 按住按钮采集动作，松开后识别，降低误触。
- 自行采集并训练 3 种手势，并加入无效动作样本。
- 通过 Wi-Fi / MQTT 将手势事件发送到 Home Assistant。
- 实现指定灯具开关和一组场景；智能插座控制作为同阶段扩展。
- 记录识别率、误触、端到端延迟和断网表现。

## 技术路线（拟定）

ESP32-C3 + MPU6050 → 动作采集与预处理 → TensorFlow Lite Micro 推理 → MQTT → Home Assistant → 灯 / 智能插座。

开发框架优先评估 ESP-IDF，工具链兼容性验证后确定。第一版使用 USB 低压供电和模块搭建；电池、PCB、外壳在功能验证后推进。
