# 电机驱动板 V2 改版记录

> 日期：2026-11-05
> 起因：V1 回板后手焊反复失败，默认焊盘太小
> 范围：**只改 PCB**（封装焊盘 / 布局布线 / 板框），原理图与 BOM 未动
> 状态：已提交嘉立创免费打样，所需元件已下单

---

## 一、为什么要改

V1 是第一次打样，封装全部用库里的默认焊盘。回板后 U1、U2、U3、U4、U5、Q1 六处反复补焊都不成功，复盘下来是三个叠加因素：

| # | 问题 | 表现 |
|---|---|---|
| 1 | 焊盘几乎与引脚等宽，**没有外伸量（toe/heel fillet）** | 烙铁头贴不到焊盘，锡堆在引脚上却不润湿焊盘，形成"假焊" |
| 2 | 相邻焊盘之间没有余量 | 一拖焊就连锡，越补越糟 |
| 3 | 散热焊盘直接连大面积铺铜，**散热过快** | 烙铁功率不够，焊锡在熔点附近就凝固，焊点发乌 |

结论：不是手法问题，是封装尺寸给得太紧。**V2 把六个封装全部重建，按 IPC-7351 的最大实体一侧取焊盘尺寸，不再用库默认的最小值。**

---

## 二、六项改动

| # | 改动 | V1 | V2 | 目的 |
|---|---|---|---|---|
| 1 | **重建 U1/U2/U3/U4/U5/Q1 封装，加大焊盘** | 库默认最小焊盘 | 焊盘加宽、加长，留出爬锡台阶 | 手工焊接与返修可行 |
| 2 | **重排元件位置** | 70×50 内分散布置 | 50×50 内紧凑布置，功率与信号分区更明确 | 缩短功率回路，腾出中心区 |
| 3 | **板框 70×50 → 50×50** | 3500 mm² | 2500 mm²（**−29%**） | 可直接装在夹爪/机械臂末端 |
| 4 | **U5 编码器移到板中心** | 右下角 | 板几何中心，与电机轴线共线 | 磁铁装在电机轴尾端即可正对芯片 |
| 5 | **四角加固定孔** | 无 | 4 × ∅3mm 非金属化孔，孔距约 46 × 46mm | 螺钉直接固定在结构件上 |
| 6 | **背面整片铺铜** | 底层以走线为主 | 底层整片 GND 铺铜 | 双面地，回流路径更短、更抗干扰 |

板框比例已在预览图上核对：板框外沿 1341 × 1341 px，长宽比 **1.000**，是正方形，与 50 × 50mm 一致。

## 三、新布局分区

```
        ┌──────────────────────────────────────────┐
   ○    │ J1 XT30   F1  Q1  D1/D2   C23  C1        │    ○
        │  ┌────────┐        ┌───────────────┐    │
        │  │ ① 输入 │        │ ② 降压  U1 L1 │    │
        │  │ 保护   │        │   U2  C2~C7   │    │
        │  └────────┘        └───────────────┘    │
        │        ┌──────────────┐                  │
        │   U6   │   U5 AS5600  │   R8 R9   J6     │
        │  eFuse │  （板中心）  │   C14 C15        │
        │        └──────────────┘                  │
        │  J2    ┌──────────────┐   U4  D3  JP1    │
        │ 电机   │ ③ U3 TMC2209 │   ④ CAN   J5     │
        │ 端子   │   R1 R2 C8~11│                  │
        ├────────┴──────────────┴──────────────────┤
        │  J4 1×11P 排针（接 ESP32）               │
        └──────────────────────────────────────────┘
   ○                                                   ○
```

- **左上**：XT30 进线 → F1 → Q1 反接保护 → D1/D2 钳位 → C23/C1 母线电容
- **右上**：U1（LMR33630）+ L1 + U2（TLV75533），开关回路集中在角上，远离中心
- **左中**：U6（TPS26600 eFuse），RTN 依旧全程浮离 GND
- **正中心**：U5（AS5600），四周留空，方便贴磁铁和后期加屏蔽
- **右下**：U3（TMC2209）+ R1/R2 采样，紧邻 J2 电机端子
- **右侧**：U4（TCAN3413）+ D3 + JP1 终端跳线 + J5 测试点
- **下沿**：J4 11P 排针，杜邦线向板外走，不跨板面

## 四、焊盘重建的做法

| 位号 | 器件 | 改动 |
|---|---|---|
| **U1** | LMR33630（同步降压） | 功率引脚焊盘加宽加长；SW 与相邻焊盘留出跨接 BOOT 电容的空间，自举回路仍然最短 |
| **U2** | TLV75533（SOT-23-5） | 三个短边外伸加大，单脚可独立补锡，不用整排拖 |
| **U3** | TMC2209（QFN-28） | 四周焊盘向外延伸，侧面能形成可见爬锡；EP 仍打 3×3 过孔阵列 |
| **U4** | TCAN3413（SOP-8） | 焊盘加长，脚尖露出芯片本体外，方便逐脚点焊 |
| **U5** | AS5600（SOIC-8） | 焊盘加长加宽，八个脚都能单独下烙铁；本体居中 |
| **Q1** | PMOS 反接保护（SOT-23） | 三个焊盘整体放大，漏极散热焊盘加宽 |

原则：**只放大焊盘，不动引脚间距**。间距保持原样，连锡风险才不会随焊盘一起变大。

## 五、编码器居中：几何关系

AS5600 检测的是芯片正上方磁铁的**径向磁场分量**，芯片中心与磁铁中心的偏差直接吃精度。V1 把 U5 放在右下角，磁铁得靠一根偏心支架伸过去，同轴度没法保证；V2 直接把 U5 放到板中心。

- 板中心坐标：**(25, 25)** mm
- U5 本体中心与板中心重合（预览图上偏差 < 1mm，按板框 26.8 px/mm 量得）
- 装配时让 **42 电机轴穿过/对准板中心**，磁铁压在轴尾，芯片自然在磁铁正下方

装配要点（AS5600 数据手册）：

| 项 | 要求 |
|---|---|
| 磁铁 | 直径 6mm、厚 2.5mm 的径向充磁圆片（NdFeB） |
| 气隙（磁铁端面到芯片表面） | **0.5 ~ 3mm**，推荐 1~2mm |
| 径向偏心 | 尽量 < 0.5mm，偏心越大角度误差越大 |
| 干扰 | 磁铁附近不要放铁磁结构件；电机自身磁场会引入偏移，需实测零点 |

> 编码器仍是**预留**：调试阶段不焊 U5，先用开环 + 撞限位回零。

## 六、板框与固定

| 项 | 数值 |
|---|---|
| 外形 | 50 × 50mm 正方形，四角圆角 |
| 层数 / 板厚 | 2 层 / 1.6mm |
| 安装孔 | 4 × ∅3mm，非金属化，孔心距板边约 2mm |
| 孔距 | 约 46 × 46mm |
| 板中心 | 即电机轴位置，也是 U5 位置 |

⚠️ 孔壁到板边只剩约 0.5mm，**M3 螺钉不要过度拧紧**，建议加平垫分散压力；孔位与结构件之间加绝缘垫，避免背面铺铜被螺钉头压穿阻焊后短路。

## 八、回板验证重点（V2 新增项）

除沿用 V1 的上电检查清单外，V2 要额外确认：

- [ ] **连锡**：U3（QFN-28）四周、U1 相邻功率脚，先目视 + 万用表蜂鸣档逐对测
- [ ] **焊盘吃锡**：这次焊盘外伸了，焊点应该是"脚—焊盘"连续的凹面，不再是球状
- [ ] **固定孔**：螺钉拧入后量孔壁与 GND 铜的阻值，应为开路；装结构件后复测一次
- [ ] **同轴度**：电机装好后，用卡尺量磁铁中心与 U5 中心的偏差，目标 < 0.5mm
- [ ] **气隙**：装配后磁铁端面到芯片表面，1~2mm 为宜
- [ ] **底层铺铜**：与金属外壳/结构件之间必须有绝缘，重点看四角螺钉处
