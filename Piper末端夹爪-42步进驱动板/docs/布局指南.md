# 电机驱动板 · 器件放置指南

> 适用：LMR33630 + TLV75533 + TMC2209 + TCAN3413 + AS5600（预留）
> 目标板尺寸：约 40 × 40mm，2 层，1.6mm

---

## 一、五条铁律（画板前先记住）

| # | 规则 | 违反的后果 |
|---|---|---|
| 1 | **功率回路优先**：24V 入口 → F1 → Q1 → U3 的电流路径，越短越粗越好 | 母线振铃、效率下降、EMI 超标 |
| 2 | **去耦电容贴脚**：电源脚到电容 ≤3mm，先过电容再走远 | 电容等于没装，出现"查一周查不出"的偶发故障 |
| 3 | **地要分区但单点汇合**：PGND 一片铜，AGND 一小片，只在 U1 的 EP 下方连 | 开关噪声窜进反馈和 ADC |
| 4 | **敏感信号远离功率**：CAN 差分对、FB 分压、分压采样，离 SW/L1/电机线 ≥10mm | CAN 误码、电压采样跳动 |
| 5 | **功能电容跨脚**：C17/C18/C19 是"跨在指定两脚之间"的，不是对地去耦 | 输出 0V 或电机完全不转 |

## 二、分区平面图

```
        ┌─────────────────────────────────────┐
        │  ① 电源入口        ② 降压 + 5V      │
   XT30 │  J1 F1 Q1 D1 D2 C1   U1 L1 C2 C3    │
   四芯 ─┤                      C6 C17 C4 C5  │
        │                      R11 R12 U2 C7  │
        ├─────────────────────────────────────┤
   电机 │  ③ 步进驱动        ④ CAN            │
   四芯 ─┤  U3 R1 R2 C8~C11   U4 D3 R4 JP1    │
        │  C18 C19 J2         C12  +VIO电容   │
        ├─────────────────────────────────────┤
        │  ⑤ MCU 接口        ⑥ 编码器（预留） │
        │  J4 R5 R6 C13 R7    U5 C14 C15      │
        │  R10 LED1 J5        R8 R9           │
        └─────────────────────────────────────┘
             ↑ J4 排针朝板边，杜邦线向板外
```

**分区理由**：电源从左上进来，降压在右上，功率驱动在左下，通信在右下——**功率走一边，信号走另一边**，中间用地线隔开。

## 三、电源入口区

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **J1** | KF128-2.54-4P | 24V + CAN 输入 | 板边，端子开口朝板外；丝印标清 1=24V 2=GND 3=CANH 4=CANL |
| **F1** | PPTC 1.5A | 过流保护 | **紧贴 J1 的 24V 针，≤5mm**。它是第一道关卡，放远了保护范围就漏了 |
| **Q1** | HSBB6115 PMOS | 反接保护 | 紧跟 F1，≤8mm；**8 个焊盘全焊**，源极/漏极各用一整片铜（宽 ≥1.5mm） |
| **D1** | BZT52C12S | 栅极钳位（12V） | **必须紧贴 Q1 的 G 和 S 脚，≤5mm**。钳位回路一长，栅极会有尖峰 |
| **R14** | 10kΩ（现在 24.9k/47k，**要改**） | 栅极下拉 | 和 D1 一起放在 Q1 栅极旁，G→GND 走线 ≤5mm |
| **D2** | SMF26CA TVS | 吸收瞬态尖峰 | 放在 Q1 漏极（VM_24V）出口处，≤5mm；**地端就近打过孔**，不要绕 |
| **C1** | 100µF/50V 电解 | 输入储能 | 靠近 24V 入口与 Q1 输出之间；离 U3 的 VS 控制在 15mm 内；注意极性 |

**这一区的关键**：从 J1 到 Q1 漏极，电流路径是一条线，全部走 ≥1mm 宽铜，**不要在这条路上开任何分支给别的电路**。

## 四、降压区（U1 + U2）

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **U1** | LMR33630 | 24V→5V/3A | 板中部偏上；**SW 脚朝向 L1**；EP 打 ≥9 个过孔到地平面 |
| **C2、C3** | 10µF/50V 1206 | U1 输入高频去耦 | **≤3mm，各贴 pin2 和 pin10**。这是全板最敏感的两颗，宁可挤也要挤进去 |
| **C17** | 100nF | BOOT 自举 | **跨 pin4↔pin12，≤2mm，顶层不打过孔**。TI 特意把 pin3 空出来就是为了让它抄近路 |
| **C6** | 1µF | U1 内部 LDO 旁路 | 贴 pin5，≤2mm |
| **L1** | 4.7µH | 储能电感 | **≤3mm 贴 SW**，走线宽 ≥1mm；下方不要走信号线 |
| **C4、C5** | 22µF | 5V 输出滤波 | L1 输出端；一颗靠 L1，一颗靠 U2 输入；**FB 取样从它们正端取** |
| **R11、R12** | 100k / 24.9k | FB 分压 | 靠近 U1 pin7，≤5mm；分压中点走线短；**远离 SW 和 L1 ≥5mm** |
| **U2** | TLV75533 | 5V→3.3V | 靠近 3.3V 负载中心（U3 与 U4 之间） |
| **C7** | 1µF | U2 输出电容 | **≤2mm 贴 OUT 脚**，地就近 |
| **C16** | 100nF | U2 输入去耦 | **≤2mm 贴 IN 脚** |

**这一区的关键**：SW 节点（pin12 + pin3 + L1 + C17）是整块板**最强的辐射源**，2.1MHz。这一小片铜**面积越小越好**，周围不要有任何长走线经过。

## 五、步进驱动区（U3）

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **U3** | TMC2209 | 步进驱动 | 功率区中心；**EP 铺铜 + ≥16 个 0.3mm 过孔**；上方留出散热片空间 |
| **R1、R2** | 110mΩ 1W | 相电流采样 | **≤3mm 贴 BRA/BRB**；**开尔文接法**：采样线从焊盘内侧引，等长平行，不与功率路径重叠 |
| **C9** | 10µF/50V | VS 储能 | ≤3mm 贴 pin22 或 pin28 |
| **C11** | 100nF | VS 高频去耦 | ≤2mm 贴 VS 脚，与 C9 同一侧 |
| **C8** | 100nF | VCC_IO 去耦 | ≤2mm 贴 pin15 |
| **C10** | 2.2µF | 5VOUT 去耦 | ≤2mm 贴 pin8，地回路最短 |
| **C18** | **22nF** | 电荷泵飞电容 | **跨 pin4↔pin5，≤2mm**；顶层直连，**不打过孔**，下方不走线 |
| **C19** | **100nF** | VCP 储能 | 跨 pin6 ↔ VS（pin22/28）；这是 29V 节点，走线短、间距够 |
| **R3** | 1kΩ | UART 串阻 | 靠近 pin14，串在 MCU TX 那一侧 |
| **J2** | KF128-2.54-4P | 电机四线 | 板边，四根走 ≥0.5mm；**离 CAN 差分对 ≥10mm，交叉走 90°** |

**这一区的关键**：U3 是唯一会明显发热的器件，EP 的过孔数量直接决定能不能跑满电流。16 个 0.3mm 孔不是"建议"，是下限。

## 六、CAN 区

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **D3** | PESD1CAN | 总线 ESD 保护 | **紧贴 J1 的 CAN 针，在 U4 之前**；pin3 地**就近打过孔，<3mm** |
| **R4** | 120Ω | 终端电阻 | 靠近 J1/CAN 入口；终端的价值在于"在最末端"，放远了没意义 |
| **JP1** | 2P 跳线 | 终端开关 | 与 R4 相邻，**要能插拔**——别被结构件或散热片挡住 |
| **U4** | TCAN3413 | CAN 收发器 | 靠近 J1 的 CAN 侧；TXD/RXD 走线短 |
| **C12** | 100nF | VCC 去耦 | ≤2mm 贴 pin3 |
| **新增 100nF** | 100nF | VIO 去耦（pin5） | ≤2mm 贴 pin5，与 C12 分列芯片两侧 |
| **SHDN,VIO(pin5)** | — | 接 3.3V | 走线从 +3V3 就近引，不要绕远 |
| **J3** | XH2.54-2P | 抓包口 | 板边或 U4 旁；**支线 <10mm**；不用可以不焊 |

**这一区的关键**：CAN_H/CAN_L 必须**成对走、等长、平行、间距 ≥3 倍线宽**，全程不跨分割地，不与电机线平行。

## 七、MCU 接口区

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **J4** | 11P 排针 | 接 ESP32 开发板 | 板边，针朝板外；**GND 放第 1 针**；丝印逐针标注 |
| **R5、R6** | 100k / 10k | 母线分压 | 靠近分压取样点；**整个分压网络放在信号区**，远离 SW/L1/U3 的功率回路 |
| **C13** | 100nF | 分压滤波 | 贴 R6，≤3mm |
| **R7** | 10kΩ | STB 下拉 | **贴 U4 pin8，≤5mm**。不要放 J4 那边——下拉要靠近被保护的引脚 |
| **R10** | 1kΩ | LED 限流 | 与 LED1 相邻 |
| **LED1** | 0805 绿 | 3.3V 指示 | 板边可见处，靠 J5 的 3V3 测试点 |
| **J5** | 1×4P 排针 | 测试点 | 板边一排，四针挨着；丝印标 24V/5V/3V3/GND |

## 八、编码器（预留，调试阶段不焊）

| 位号 | 值 | 作用 | 放置要求 |
|---|---|---|---|
| **U5** | AS5600 | 磁编码器 | **调试阶段无要求——放板边即可**。装机阶段必须落在**板的几何中心**，且与电机轴同心（误差 <0.5mm），那时整个分区要重排 |

## 九、八个"摆错就废"的项（按严重程度排）

| 排名 | 器件 | 错了会怎样 |
|---|---|---|
| 1 | **C17**（BOOT） | 高边 MOS 打不开，**输出 0V**，整板没电 |
| 2 | **C18**（22nF 电荷泵） | 高边栅极没电压，**电机完全不转**，STEP 有脉冲也没用 |
| 3 | **C19**（VCP） | 同上，或大电流时丢步发热 |
| 4 | **C2、C3**（U1 输入） | 24V 母线上出现 2.1MHz 纹波，干扰全板 |
| 5 | **R1、R2**（采样） | 不开尔文 → 电流读数系统性偏大 → 电流环振荡 |
| 6 | **D3**（PESD1CAN） | 放 U4 之后 → 浪涌先打穿收发器再被钳 |
| 7 | **R7**（STB 下拉） | 放远了 → 悬空拾取干扰 → 偶发进待机，CAN 时通时断 |
| 8 | **R14**（栅极下拉） | 阻值错（现在 24.9k/47k）→ 稳压管钳不住，PMOS 可能不导通 |

## 十、地平面的处理

```
PGND（一整片）                    AGND（一小片）
├─ C1/C2/C3 负极                  ├─ R5/R6 分压地
├─ U1 pin1/pin11                  ├─ C13 地
├─ U1 的 EP                       ├─ U4 pin2
├─ U3 的 EP（16 孔）              ├─ U5 pin4
├─ R1/R2 地                       └─ R8/R9 地
├─ C9/C11/C10/C8 地
└─ U2 的 EP、C7 地                    │
        │                             │
        └────── 单点汇合于 U1 EP 下方 ┘
```

**做法**：顶层和底层各铺一整片地，PGND 与 AGND 之间用一条 1~2mm 的窄桥连接（就在 U1 的 EP 正下方），其他位置不许连。

## 十一、画完 PCB 的自查清单

- [ ] 每颗 100nF 到它服务的电源脚，距离 ≤3mm（用测量工具逐个量）
- [ ] C17 跨 pin4-pin12，全程顶层，无过孔
- [ ] C18 跨 pin4-pin5，全程顶层，无过孔
- [ ] C19 一端在 pin6，另一端在 VS（不是 GND）
- [ ] R1/R2 的采样线从焊盘内侧引出，两条等长
- [ ] D3 在 J1 与 U4 之间（看信号流向，不是看距离）
- [ ] 电机四线与 CAN 差分对的最小间距 ≥10mm
- [ ] U3 的 EP 过孔数 ≥16
- [ ] 功率路径（J1→F1→Q1→U3）铜宽 ≥1mm，无细颈
- [ ] FB 取样点从 C4/C5 正端取，不从 L1 后面取
- [ ] 丝印标清 J1 四位、J2 四位、J4 十一位、JP1 默认不插
