## 三、问题清单

### ✅ 问题 1（已更正）：EF_RTN 不接 GND 是**正确**的，不能加 R18

**本报告初版误判为"必须接地"，此处更正。**

TI 数据手册 9.3.5.5 节原文：
> Internally, the device has reverse input polarity protection block **between RTN and the GND terminal**. **Connecting RTN pin to GND pin disables the reverse input polarity protection feature** and the TPS2660x gets permanently damaged when operated under this fault event.

TI 数据手册 10.4 节 Do's and Don'ts 第一条：
> **Do not connect RTN to GND.** Connecting RTN to GND disables the Reverse Polarity protection feature

TI E2E 官方工程师（Amrit Jit）的解释最清楚：
> 在 TPS2660 器件中，**当输入电压为正时，RTN 在内部连接到 GND**；当输入端出现负电压（反极性）时，**RTN 从 GND 断开**。

**机制**：RTN 并不是"需要外部接地才能工作的地"，而是芯片特意留出的**浮动控制参考**。正常工作时内部开关把它并到 GND（因此 R5/R17/C21 的参考电位就是地）；一旦输入反接，内部开关断开，RTN 跟着输入一起下沉到负电位，反接保护块才能正常工作。

若在外部用 0Ω 把 RTN 短到 GND：反接时 RTN 被钉死在 0V，而 IN 是 −24V，保护块失效 → **芯片永久损坏**。

**当前 PCB 状态**：`EF_RTN` 7 个连接点（U6 pin3/pin6/pin8/pin17、R5 下端、R17 下端、C21 下端）全部悬空于 GND 之外，**完全符合 TI 要求，无需任何改动，也不要加 R18**。

同时这也验证了 R5（OVP 分压）、R17（ILIM）、C21（dVdT）、UVLO、MODE 全部接 RTN 的做法是对的——手册要求这些支撑元件必须以 RTN 为参考。

### ✅ 问题 1b（已修复）：U6 的 EP 补了 9 个散热过孔

**修改前**：`EF_RTN` 网络过孔数 = **0**，EP 只靠顶层 10mil 细走线。

**已执行**：在 EP 焊盘（2.3×2.5mm，中心 565,715 mil）上打 **3×3 = 9 个过孔**，0.3mm 孔 / 0.6mm 外径，全部 `EF_RTN` 网络。

| 参数 | 值 |
|---|---|
| 坐标（mil） | x = 533.5 / 565 / 596.5，y = 686 / 718 / 750 |
| 列间距 | 31.5 mil（间隙 7.5 mil） |
| 行间距 | 32 mil（间隙 8 mil） |
| 距 EP 下边缘 | 8 mil（与下方 OVP 走线保持 0.203mm） |
| 距 EP 上边缘 | 2.4 mil |

**初版排布曾报 3 个 DRC 错误**（最下行过孔与 `$1N238` 走线间距 0.133mm < 0.152mm），整体上移 2.5mil 后清零。

**关于底层铜块**：原计划在底层铺 EF_RTN 铜块承接，实测**空间不足**——底层 `$1N238`（OVP 分压连线）水平走线在 y=661，紧贴 EP 下边缘（665.6），只剩 4.6mil；`VM_24V` 也在 EP 下方 13.6mil 处。要留出 0.5mm 反接安全间距就放不下铜块。

**所以底层未补铜**，9 个过孔目前只连顶层焊盘。实际影响很小：U6 在 0.6A 时耗散 `0.6²×0.15 = 54mW`，EP 焊盘自身面积足够；跑到 1.5A 限流点时 338mW，也远未到需要强制散热的程度。若后续要装铜块，需要先把 `$1N238` 走线改道。

### 🟡 问题 3：电流采样电阻离芯片 10mm（实际电流低 19%）

| 项 | 实测 | 目标 |
|---|---|---|
| R1 → U3 pin23 (BRA) | **423 mil = 10.8mm** | ≤3mm |
| R2 → U3 pin27 (BRB) | **400 mil = 10.2mm** | ≤3mm |
| BRA 走线总长 | 15.4mm | — |
| BRB 走线总长 | 12.4mm | — |

15mm × 10mil 铜走线约 **0.03Ω**，把 0.11Ω 采样电阻变成 0.14Ω：

```
设定 IRUN=18（1.05A RMS）→ 实际约 0.85A RMS
保持力矩 0.39 → 0.32 N·m（降 19%）
```

**处理**（二选一）：
1. **挪 R1/R2** 到 U3 的 pin23/27 旁（最优，顺带解决开尔文接法）
2. 不动布局，把 BRA/BRB **加宽到 30mil**（误差降到 9%），固件里 IRUN 调到 22 补偿

### 🟡 问题 4：BOOT 电容 C16 距 3.5mm

| 项 | 实测 | 目标 |
|---|---|---|
| C16 → U1 pin4 (BOOT) | 143.7 mil = 3.65mm | ≤2mm |
| C16 → U1 pin12 (SW) | 133.5 mil = 3.4mm | ≤2mm |

BOOT 电容跨 BOOT/SW，是自举回路核心。2.1MHz 下 3.5mm 走线电感会让自举回路振铃、抬 EMI。**建议挪进 2mm 内，顶层直连不过孔。**

### 🟡 问题 5：电机线与 CAN 线间距 3.9mm

| 项 | 实测 | 目标 |
|---|---|---|
| OA1/OA2/OB1/OB2 ↔ CAN_H/CAN_L 最小边距 | **153 mil = 3.9mm** | ≥10mm |

最近一对是 OA2 与 CAN_H（底层）。对 1Mbps CAN + 1A 斩波电机线，属于"能用但不理想"，总线负载高时可能偶发误码。

**处理**：空间允许就把 CAN 差分对往板边再推 5mm；否则靠差分抗共模能力兜底。

### 🟡 问题 6：全部走线 10mil，电源线未加宽

| 线宽 | 条数 |
|---|---|
| 10 mil (0.254mm) | 546 |
| 8.86 mil (0.225mm) | 77 |

**没有一条加宽的电源走线。** 温升估算：

| 网络 | 电流 | 10mil 温升 |
|---|---|---|
| VM_IN / VM_P / VM_PRE / VM_24V | 0.6A | 15~20°C |
| OA1/OA2/OB1/OB2 | 1.05A RMS | **40~50°C** |

能工作，但电机相线偏热、压降影响电机实际电压。**建议把四路电源和四条电机线加宽到 20~30mil。**

### 🟡 问题 7：没有安装孔

59 个元件里没有 H1/H2，46 个过孔全部带网络。板子 64×48mm，装机需要至少 2 个 M3 孔。

**建议**：四角加 2~4 个 Ø3.2mm 非金属化孔，与 GND 铺铜保持 0.5mm 间隙。
