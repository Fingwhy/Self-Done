# 机械臂末端夹爪驱动板 · 项目总结

> 对象：松灵 Piper 六轴机械臂 J6 末端自制夹爪
> 版本：原理图 v2（2026-10-30）
> 平台：嘉立创 EDA 专业版，2 层板

---

## 一、项目目标

给 Piper 的 J6 末端做一个**自制夹爪**，替代官方夹爪。分三条线并行：

| 线 | 内容 | 状态 |
|---|---|---|
| **机械** | SolidWorks 建模，齿轮齿条传动，开口 20mm，m1.5 z14 | 结构方案已定 |
| **电子** | 嘉立创 EDA 画驱动板，末端四线取电 + CAN 通信 | **原理图 v2 完成** |
| **控制** | ESP32 收 CAN 指令驱动电机（开发板外置，杜邦线连） | 待开发 |

---

## 二、系统架构

```
Piper 主控 ──CAN 1Mbps──┐
                        │  XT30 2+2（24V/2A + CAN_H/L）
                    ┌───┴─────────────┐
                    │   驱动板 v2      │
                    │  24V→5V→3.3V    │
                    │  TMC2209        │
                    └───┬─────────────┘
                        │ 四相线
                    ┌───┴────┐        ┌──────────┐
                    │ 42CM04 │──齿轮──│ 夹爪机构 │
                    └────────┘        └──────────┘
                        │
                  J4 排针（11P，杜邦线）
                        │
                  ESP32 开发板
```

**关键定位**：驱动板不含 MCU。ESP32 用现成开发板，通过 2.54 排针连接。这样调试期可以随时换板、烧程序，不必拆焊。

## 三、驱动板实现的功能

### 1. 电源输入与四级保护

| 级 | 器件 | 设定 | 作用 |
|---|---|---|---|
| 接口 | **XT30 2+2 板端公头**（AMASS PB-M） | 15A 额定 | 与原厂线缆直接对插，防误插 |
| 过流 | **PPTC 1.5A** | 保持 1.5A / 跳闸 3A | eFuse 失效时的后备 |
| 反接 | **HSBB6115 PMOS** + BZT52C12S + 10k | Vgs 钳在 −12V | 24V 接反不烧板 |
| 瞬态 | **SMF26CA** 双向 TVS | 26V standoff | 吸收电机制动回灌、插拔尖峰 |
| **智能保护** | **TPS26600 eFuse** | 限流 **1.46A**、OVP **27.4V**、UVLO **14.9V** | 见下 |

**eFuse 是这块板最有价值的部分**，因为它保护的不只是自己，还有共用的机械臂母线：

| 功能 | 参数 | 意义 |
|---|---|---|
| 可编程限流 | R17=8.2k → 1.46A（±5%） | 不会像 PPTC 那样随温度漂移误跳闸 |
| 过压切断 | R16/R5=220k/10k → 27.4V | 挡住制动回灌的持续过压 |
| 欠压锁定 | UVLO 接 RTN → 出厂 14.9V | 母线跌落时主动断开，不拖垮主控 |
| 软启动 | C21=22nF → 5.26V/ms | 插拔瞬间不产生浪涌 |
| 反接保护 | 背靠背 FET，−60V | 与 Q1 形成双重保险 |
| 故障响应 | MODE 接 RTN → **主动限流 + 自动重试** | 电机堵转时限流不断电，过热后 512ms 自恢复 |

### 2. 三级电源变换

| 级 | 器件 | 指标 | 配套 |
|---|---|---|---|
| 24V→5V | **LMR33630**（2.1MHz 同步降压） | 3A | C2/C3 10µF 输入、C4/C5 22µF 输出、C16 100nF BOOT、C6 1µF VCC、L1 4.7µH |
| 5V→3.3V | **TLV75533**（500mA LDO） | 500mA，压差 1.7V | C20 1µF 输入、C7 1µF 输出 |
| 反馈 | R11/R12 = 100k/24.9k | **5.02V** | 1% 精度 |

**为什么降压后再 LDO**：LDO 在 1k~100kHz 有 50~60dB 抑制，把开关纹波压掉两个数量级。3.3V 供给 CAN 收发器和 ADC 分压，干净程度直接决定误码率和采样精度。

### 3. 步进驱动（TMC2209）

| 项 | 配置 |
|---|---|
| 工作模式 | UART（MS1/MS2 接地 → 地址 0） |
| 细分 | 1/16（`MSTEP`）+ MicroPlyer 内部插值到 1/256 |
| 斩波 | StealthChop2（`SPREAD` 接地），几乎无啸叫 |
| 电流 | `IRUN=18` → **1.05A RMS**（电机额定 1.5A 峰值的 99%） |
| 采样电阻 | R1/R2 = **110mΩ**（满量程 1.77A RMS） |
| 电荷泵 | C18 = **22nF**（CPO↔CPI）、C19 = 100nF（VCP↔VS） |
| 使能 | ENN 经 R7 10k 上拉 → **ESP32 未上电时默认禁用**，防止上电乱动 |
| 诊断 | pin11 `DIAG` → **J4 第 11 针**（可读 StallGuard 中断） |
| 散热 | QFN-28 EP 铺铜 + ≥16 过孔 + 8×8 散热片 |

### 4. CAN 通信

| 项 | 配置 |
|---|---|
| 收发器 | **TCAN3413**（3.3V，CAN FD 兼容，总线耐压 ±58V） |
| 速率 | 1Mbps（Piper 固定） |
| 保护 | **PESD1CAN**（24V standoff、11pF、±23kV ESD） |
| 终端 | **120Ω + JP1 跳线**，默认不装 |
| 去耦 | C12（VCC）、C17（VIO）各 100nF |
| 模式 | STB 经 R13 10k 下拉 → **默认正常工作模式** |
| 抓包 | ~~J3 2P~~（v2 已删，需临时并在 J1 上） |

**一个关键设计**：STB 下拉保证「ESP32 没上电时收发器仍在正常模式，照样回 ACK」。这是"只收不发"方案能成立的前提——否则主控会累积 ACK 错误，最终 bus-off。

### 5. 检测与指示

| 功能 | 实现 | 用途 |
|---|---|---|
| 母线电压 | R15/R6 = 150k/10k → 24V 对应 1.5V，36V 对应 2.25V | 监测母线是否被拉低（防拖垮机械臂） |
| 滤波 | C13 100nF（约 175Hz 低通） | 让 ADC 读数稳定 |
| 测试点 | **J5 1×4P**：24V / 5V / 3V3 / GND | 上电 30 秒定位故障级 |
| 电源指示 | LED1（+3.3V）+ R10 1k | 亮 = 三级电源全通 |

### 6. 接口

| 接口 | 类型 | 用途 |
|---|---|---|
| **J1** | XT30(2+2)PB-M 板端公头 | 原厂线缆直插：24V / GND / CAN_H / CAN_L |
| **J2** | KF128-2.54-4P 螺钉端子 | 电机四相（OA1/OA2/OB1/OB2，同相相邻） |
| **J4** | 1×11P 排针 | 接 ESP32：GND、STEP、DIR、EN、TMC_TX、UART_LINE、CAN_TX、CAN_RX、CAN_STB、VBUS_S、**DIAG** |
| **J5** | 1×4P 排针 | 四个电源测试点 |
| **J6** | 1×2P 排针 | I2C（SDA/SCL），供 AS5600 使用 |

### 7. 预留编码器

**AS5600** 磁编码器（SOIC-8）+ 两颗 100nF + I2C 4.7k 上拉，SDA/SCL 引到 J6。
调试阶段不焊，装机阶段用于**闭环防丢步**。

## 四、关键设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| 供电 | **直接用末端 24V/2A**，不外接 | 免共地、免地环路、免抗扭走线；代价是 48W 上限 |
| 通信 | **只收 CAN（0x159）**，TWAI 用 NORMAL 模式 | LISTEN_ONLY 不回 ACK 会把主控拖到 bus-off |
| 主控 | **ESP32 开发板外置** | 调试期换板/烧录方便，驱动板只需一次打样 |
| 驱动 | **TMC2209** 而非 DM1-422 | 110g→5g、体积 1/20、静音、UART 可配、StallGuard |
| 力控 | **弹性夹指**（机械保证） | 步进恒流，电气上测不到夹持力 |
| 保护 | **eFuse** 而非纯 PPTC+PMOS | 阈值精确、软启动、过压/欠压可编程 |
| 连接器 | **XT30 板端公头**，不用转接线 | 少一个接头，插拔力由 PCB 承担 |

## 六、设计评审中发现并修正的问题

| # | 问题 | 后果 | 修正 |
|---|---|---|---|
| 1 | Q1 源漏接反 | 反接保护失效 + 启动时 Vgs=−24V 超栅极极限 | 改为 D=输入、S=输出（新增 `VM_PRE` 网络） |
| 2 | TMC2209 缺电荷泵电容 | 电机完全不转 | 补 C18 22nF + C19 100nF |
| 3 | LMR33630 缺 FB 分压与 BOOT 电容 | 无 5V 输出 | 补 R11/R12 + C16 |
| 4 | U4 的 VIO 无去耦 | CAN 误码率上升 | 补 C17 |
| 5 | AS5600 的 I2C 未引出 | 编码器装了也读不到 | 加 J6 |
| 6 | **EF_RTN 悬空** | **整板不上电** | 曾用 R18 0Ω 修好，**v2 又被删掉，需补回** |
| 7 | J1 焊盘编号与物理引脚冲突 | 24V 可能打到信号针 | 按几何分配 + 焊前实测 |
| 8 | C22 1µF 输入电容偏小 | 限流动作时输入振铃 | 改 C24 10µF |

## 八、已知限制（诚实清单）

| 限制 | 原因 | 影响 | 应对 |
|---|---|---|---|
| **开环丢步** | 步进无位置反馈 | 夹住物体后位置漂移 | 每次张开撞限位回零；后期用 AS5600 |
| **无夹持力读数** | 恒流驱动，电流不携带负载信息 | 做不了精确力控 | 弹性夹指（力=刚度×压缩量） |
| **StallGuard 静止失效** | 反电动势只在转动时存在 | 夹住后读不到 | 只用于"碰到即停" |
| **2A 共享母线** | 与六个关节共用 | 大电流会拖垮主控 | eFuse 限流 1.46A + 软启动 |
| **夹持力上限 25N** | PETG 齿轮齿根强度 | 夹不紧硬物 | 齿宽加到 8mm 或换 POM |
| **XT30 插拔寿命 100 次** | 连接器规格 | 调试期易耗尽 | J1 换成端子；或备件 |
| **I2C 只到 J6** | J4 只有 11 针 | 编码器需额外两根杜邦线 | 可接受（调试期不装） |

## 九、CAN 协议速查

| 方向 | ID | 内容 |
|---|---|---|
| 主控 → 夹爪 | `0x159` | Byte0-3 行程 int32 ×0.001mm；Byte4-5 扭矩 int16 ×0.001N·m；Byte6 bit0 使能 / bit1 清错；Byte7 `0xAE` 设零点 |
| 夹爪 → 主控 | `0x2A8` | 同样 8 字节，行程 + 扭矩反馈（手册未公开私有 ID） |

**注意**：`0x2A1`~`0x2A8` 是机械臂主控主动发的反馈帧，不是夹爪发的。夹爪怎么上报手册没写，需要抓包确认。
