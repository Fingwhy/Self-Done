## 零、先确认三件事

### 1. 图上元件目前全部悬空

放大看，每个元件的两端都是短引线加端点，**相互之间没有连线**。这是"放置完成、未连线"的状态，正好按下面的表连。

### 2. R13 / R14 / C17 疑似误复制

步进模块里这组 `100k + 24.9k + 100nF`，和降压模块的 `R11 + R12 + C16` 配置完全一样。

| 位置   | 位号                                  | 组合              |
| ---- | ----------------------------------- | --------------- |
| 降压模块 | R11(100k) + R12(24.9k) + C16(100nF) | U1 的 FB 分压 ✓ 合理 |
| 步进模块 | R13(100k) + R14(24.9k) + C17(100nF) | **用途不明**        |

如果本意是给 TMC2209 的 VREF 分压，阻值不对：`3.3 × 24.9/124.9 = 0.657V`，对应电流只有满量程的 26%（约 0.28A），带不动 42CM04。

**三个选择**：

- 删掉（最省事）
- 留着不焊
- 告诉我你的本意，我给正确阻值

### 3. BOOT 电容还没找到

LMR33630 的 `pin4(BOOT)` 到 `pin12(SW)` 必须跨一个 **100nF**，否则高边 MOS 不驱动，输出 0V。

9 个 100nF 里（C8, C11~C17, C19），按位置推：

| 位号       | 所在模块 | 推测用途                    |
| -------- | ---- | ----------------------- |
| C8       | 步进   | TMC2209 VCC_IO 去耦       |
| C11      | 步进   | TMC2209 VM 去耦           |
| C12      | CAN  | TCAN3413 VCC 去耦         |
| C13      | MCU  | 母线分压滤波                  |
| C14, C15 | 编码器  | AS5600 去耦 ×2            |
| C16      | 降压   | **可能是 BOOT，也可能是 U2 去耦** |
| C17      | 步进   | 配 R13/R14（待定）           |
| C19      | 步进   | TMC2209 VCP             |

**如果 C16 不是 BOOT**，就要新增一颗。下面按"C16 = BOOT"来写，如果不对你告诉我改。
