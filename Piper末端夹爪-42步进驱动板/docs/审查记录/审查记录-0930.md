## 可选优化

| 项 | 现状 | 建议 | 收益 |
|---|---|---|---|
| **C21 软启动电容** | 22nF → 启动时 570µF 需 3A，被限流；FET 峰值功耗 ≈35W | 改 **100nF** → 电流需求降到 0.66A，不触发限流，峰值功耗降到 ≈16W | eFuse 启动更温和，避免接近 SOA 边界 |
| **Q1 + D1 + R19** | 与 eFuse 的反接保护重复 | 可删（省 3 个元件、0.02Ω） | 简化；保留则当双重保险 |
| **F1 PPTC** | 与 eFuse 1.46A 限流重复 | **建议保留** | eFuse 是 MOS 结构，可能短路失效；F1 是断 open 的后备 |
