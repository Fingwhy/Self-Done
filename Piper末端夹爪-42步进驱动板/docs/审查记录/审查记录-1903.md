## 一、必须改：EF_RTN 没有接到 GND 🔴

### 现状

新增的网络 `EF_RTN` 在原理图上出现 7 次，全部集中在 U6 周围：

| 位置 | 作用 |
|---|---|
| pin3 UVLO | 欠压门限（接 RTN = 用出厂默认 14.9V） |
| pin6 MODE | 故障响应模式选择 |
| pin8 RTN | **芯片内部控制的参考地** |
| pin17 EP | 散热焊盘 |
| R17 下端 | 限流设定电阻 |
| C21 下端 | 软启动电容 |
| R5 下端 | OVP 分压下臂 |

**但这 7 处没有任何一处连到 GND。**

### 后果

TPS2660 数据手册对 RTN 的定义是：`Reference for device internal control circuits`（内部控制电路的参考端），而 pin9 GND 是 `Connect GND to system ground`。两者在非隔离应用里必须同电位。

```
RTN 与 GND 之间没有通路
→ 内部控制电路没有回流路径
→ 内部背靠背 FET 永远不导通
→ VM_24V 输出 0V，整块板不上电
```

而且 OVP 分压、限流电阻、软启动电容全部以 EF_RTN 为参考，一起失去意义。

### 修法

在 **U6 的 pin8（RTN）脚旁，把 EF_RTN 与 GND 连起来**（一根短线即可，其他 EF_RTN 标签会自动跟随）。

推荐做法：在 EF_RTN 与 GND 之间放一个 **0Ω 电阻**（或直接连线），PCB 上就是单点接地，便于日后测量和隔离排查。

修完之后各脚的状态全部正确：

| 脚 | 修后状态 | 依据 |
|---|---|---|
| UVLO | = 0V → **出厂默认 14.9V 欠压门限** | 手册原文："Connect UVLO pin to RTN pin to select the internal default threshold" |
| OVP | 分压中点 1.04V → **27.4V 触发** | V(OVPR)=1.19V × (220k+10k)/10k |
| MODE | 0V → 需确认是哪一种故障响应（见第二节） | — |
| RTN / EP | 接系统地 | 必须 |
| SHDN | **悬空正确** | 手册：内部 1MΩ 上拉到 2.7V AVDD，可悬空 |

## 二、需要确认或小改

| # | 项 | 现状 | 建议 |
|---|---|---|---|
| 1 | **R14 栅极下拉** | 47kΩ | 改 **10kΩ**。47k 时稳压管电流仅 0.26mA，贴着拐点 |
| 2 | **MODE 脚接 RTN** | 选了某种故障响应 | 确认是"自动重试"还是"闩锁"。**建议自动重试或断路器**——闩锁型一旦误触发要断电才能恢复，装在机械臂末端很麻烦 |
| 3 | **U6 与 Q1 功能重复** | 两个反接保护串联 | TPS26600 自带背靠背 FET 反接保护（−60V），Q1+D1+R14 已冗余。可保留当双重保险（多 0.02Ω 压降），也可删掉简化 |
| 4 | **F1 与 eFuse 限流重复** | PPTC 1.5A + eFuse 1.46A | eFuse 会先动作，F1 基本永不跳闸。可保留作后备，也可删掉省 0.05Ω |
| 5 | **输入端电容** | C22 = 1µF | 手册最小要求 0.1µF 已满足，但 1.5A 级建议加到 **10µF**，抑制限流动作时的线缆振铃 |
| 6 | **C21 = 22nF（软启动）** | 输出 570µF 充电需 ~3A，会被限流 1.46A 约 10ms | 属正常范围。若想不触发限流，改 **100nF**（斜坡降到 1.16V/ms，电流需求 0.66A） |
| 7 | **J3 抓包口被删** | 1903 版没有 J3 | 调试第一步要抓 `0x159`，没有专用口只能临时并在 J1 端子上。建议加回一个 2P 排针 |
| 8 | **DIAG 仍未引出** | 打叉悬空 | J4 第 11 针空着，一根线过去即可（StallGuard 中断） |
| 9 | **安装孔** | 原理图无 | PCB 阶段补 2~3 个 M3 |

## 三、本版新增电路的参数核对

| 项 | 计算 | 结论 |
|---|---|---|
| **限流点** | R17 = 8.2kΩ → 手册 R=8k 时 1.5A | **≈1.46A** ✅ 与 2A 母线预算匹配（实际负载 0.6A） |
| **过压点** | V(OVPR)=1.19V，分压 220k/10k | **≈27.4V** ✅ 高于机械臂上限 26V，留了余量 |
| **欠压点** | UVLO→RTN，出厂默认 | **≈14.9V** ✅ 母线跌落时关断，保护机械臂主控 |
| **软启动** | dVdT 增益 24.6，C21=22nF，I=4.7µA | 输出斜坡 **5.26V/ms**，启动约 10ms（受限流钳制） |
| **输入电容** | C22=1µF | 满足手册最小 0.1µF，偏小（见第二节） |
| **输出储能** | C23=470µF + C1=100µF | 共 570µF，对 1.5A 级合理 |
| **母线下限** | 24V − eFuse 导通电阻压降 | 背靠背 FET 共 150mΩ × 0.6A ≈ 0.09V，可忽略 |
