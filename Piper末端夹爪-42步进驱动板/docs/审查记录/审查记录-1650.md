## 一、必须改的错误

### 1. Q1 源漏接反，反接保护完全失效 🔴

**现状**：`S（源极）→ VM_P（输入）`，`D（漏极）→ VM_24V（输出）`

判据来自符号本身：体二极管的**阴极（横线）在符号上方**，所以上方是源极；上方三根引线全部标 VM_P。

**后果 1：反接时后级被反向充电**

PMOS 体二极管方向是 `D → S`（阳极在漏、阴极在源）。当前接法下：

```
反接：VM_P = −24V，后级（C1、负载）≈ 0V
体二极管：阳极 VM_24V(0V)，阴极 VM_P(−24V) → 正偏导通
→ 电流从后级经体二极管灌进 −24V 电源
→ C1（100µF 电解）被反向充电 → 鼓包/爆裂，U1、U3 同时暴露在反压下
```

标准接法（D 接输入、S 接输出）时，反接后体二极管反偏，**完全阻断**。

**后果 2：上电瞬间栅极过压**

```
启动瞬间：VM_24V ≈ 0V（C1 未充电），栅极经 R14 下拉到 0V
→ Vgs = 0 − 24 = −24V
→ 此刻 D1 跨在"栅极—漏极"，两端都是 0V，不击穿，钳位不动作
→ HSBB6115 的 Vgs 极限通常 ±20V，−24V 已超限
```

**修法：只改一处 —— 把 Q1 的 S、D 两个网络对调**

两种操作任选：
- 把符号旋转 180°
- 或直接把上方标号改 `VM_24V`、下方改 `VM_P`

改完后连带成立：

| 项 | 改后状态 |
|---|---|
| D 接输入、S 接输出 | ✅ 反接时体二极管反偏，彻底阻断 |
| D1 位置 | ✅ 正好变成跨在 **栅极—源极**（阴极在源极），钳位正确 |
| 启动过程 | ✅ 体二极管先给 C1 预充电，栅极被钳在 −12V，不超限 |
| R14 | ✅ 保持栅极下拉，不用动 |

> 这就是为什么这个错误值得放在第一位：**一处交换，同时修好反接保护和栅极过压两件事。**

### 2. R14 = 47kΩ，建议改 10kΩ 🟡

稳压管钳位依赖击穿电流：

```
47k：(24 − 12) / 47k = 0.26mA   ← 贴着拐点，低温或个体差异时可能钳不住
10k：(24 − 12) / 10k = 1.2mA    ← 稳定区
```

改完后 10k 正好三颗：R6（母线分压）、R7（ENN 上拉）、R14（栅极下拉）。

## 二、功能不完备

### 1. AS5600 的 SDA / SCL 没有引到排针 🟡

现状：`U5 pin6(SDA) → R8 → +3V3`、`pin7(SCL) → R9 → +3V3`，两条线上**没有任何网络标号**，J4 的 11 个针里也没有 SDA/SCL。

结论：**编码器焊上去也读不到数据**，R8/R9 只是把两根线拉高。

两个修法：

| 方案 | 做法 | 成本 |
|---|---|---|
| A（推荐） | J4 从 11P 加到 **13P**，末尾两针接 `I2C_SDA` / `I2C_SCL` | 换连接器，零成本 |
| B | 新增一个 `1×2P` 排针（J6）专接 I2C | 多一个件 |

注意：调试阶段编码器不焊，这个问题不会立刻暴露，但**板子做出来就改不了了**。

### 2. TMC2209 的 DIAG 没有引出 🟡（可选）

`pin11 DIAG` 打叉悬空。它是 StallGuard 的硬件中断输出，将来做"夹住即停"时要用。

J4 第 11 针正好空着，**一根线接过去即可**，零成本。就算现在不用，也建议引出——板子回来再想加就没机会了。

### 3. U4 的 VIO（pin5）没有独立去耦 🟡

现在只有 C12 一颗 100nF，贴在 VCC（pin3）。手册要求 VCC 和 VIO **各**配 0.1µF，而两脚之间隔着 pin4。

建议：再加一颗 100nF 贴 pin5。（100nF 从 8 颗变 9 颗）

### 4. +3V3 没有 bulk 电容 🟡

C7（1µF）是 U2 的输出电容，之后各芯片只有 100nF 就近去耦。3.3V 侧负载约 80mA，勉强够用，但**建议加一颗 10µF** 放在 U2 输出附近，应对 CAN 收发器突发电流和开发板插拔时的瞬态。

### 5. 没有安装孔 🔴（PCB 阶段必须补）

原理图上没有任何 mounting hole 元件。这块板要装到夹爪/机械臂末端，**至少需要 2~3 个 M3 定位孔**，否则没法固定。

## 三、可接受但与常见做法有差异

| 项 | 现状 | 评价 |
|---|---|---|
| D2（TVS）位置 | 在 Q1 之后（VM_24V） | 可用。更常见是放 F1 之后、Q1 之前（VM_P），让浪涌在进 MOS 之前就被钳住。改 Q1 之后可顺手挪，不改也没问题 |
| U1 的 EN | 直接接 VM_24V | 正确（LMR33630 的 EN 可直连 VIN），但失去了欠压保护。想加就串 100k/6.2k 分压 |
| U3 的 ENN | 10k 上拉到 +3V3 | 合理。ESP32 未上电时默认禁用驱动，比默认使能安全 |
| J1/J2 端子 | KF128-2.54 4P | 电气够（0.5A vs 2A 额定），但 2.54 间距压 18AWG 线偏紧，剥线别超过 8mm |
| VBUS_S 分压 | 100k/10k，戴维南阻抗 9.1k | 在 ESP32 ADC 建议的 10k 边界上。固件里把采样时间设长（如 12dB 衰减 + 长采样）即可 |
| ADC 无钳位 | VBUS_S 直连 GPIO35 | 24V 若异常冲到 40V，分压后 3.6V 会超 ADC 绝对最大值。可加一颗 BAV99 钳到 3.3V，非必需 |
