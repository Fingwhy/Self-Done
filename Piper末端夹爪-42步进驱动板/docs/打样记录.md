### 打样前已确认的设计细节

#### 1. eFuse 的 RTN 必须浮空

`EF_RTN` 连接 U6 的 pin3(UVLO)、pin6(MODE)、pin8(RTN)、pin17(EP)，以及 R5(OVP 分压)、R17(ILIM)、C21(dVdT) 的下端，**全部不与 GND 相连**。

- 若误接 GND，反接时芯片会永久损坏（TI 手册 9.3.5.5）
- 正常工作由芯片内部把 RTN 并到 GND，控制元件因此获得地参考

#### 2. Q1 的方向

PMOS 反接保护：**D（漏极）= VM_P，S（源极）= VM_PRE**。
体二极管方向为 D→S，正常上电时正偏预充，反接时反偏阻断。栅极由 D1（12V 稳压管）钳位、R19（10k）下拉。

#### 3. U1 的 pin3

LMR33630 的 pin3 标 NC，但**必须在 PCB 上短接到 pin12 (SW)**，这样 BOOT 电容可以横跨两个相邻焊盘，自举回路最短。已连。

#### 4. 电流采样路径偏长

R1/R2 距 U3 的 BRA/BRB 约 **10.8 / 10.2mm**，铜走线串入约 0.03Ω，使实际电流比设定值低约 19%。

**应对**：固件中 `IRUN` 填 **22** 而非 18，可补偿到设计值（1.05A RMS）。

```
0.325 / (0.11 + 0.02) / √2 × (22+1)/32 ≈ 1.34 A RMS  →  扣掉走线损耗后约 1.05 A
```

### 回板后验证清单

#### 上电前（断电，万用表）

- [ ] **J1 四针与线缆的对应**：插上公头不焊，用通断档确认哪个焊盘通哪根线
- [ ] **J1 极性**：24V 在两个大焊盘之一，GND 在另一个；小焊盘是 2.5V 左右的 CAN
- [ ] **CAN_H / CAN_L**：空闲时都是 2.5V，用示波器看上升沿，或差分测平均值（H > L）
- [ ] 目视检查：U6 的 EP 过孔是否全部上锡、J1 大焊盘是否饱满

#### 上电（先不插 ESP32）

- [ ] J5 测试点：24V ± 1V / 5V ± 0.1V / 3.3V ± 0.05V / GND
- [ ] LED1 是否亮（亮 = 三级电源全通）
- [ ] U6 pin8 (RTN) 对 GND：**应为 0V 左右但不导通**（内部连接，非外部短接）

#### 接 ESP32

- [ ] 板载 3.3V **不与** ESP32 的 3.3V 相连，只共 GND
- [ ] TWAI 用 **NORMAL 模式**，不能用 LISTEN_ONLY（否则不回 ACK 会把机械臂拖到 bus-off）
- [ ] 1Mbps 收帧，确认能收到 `0x159`

#### 电机

- [ ] 空载低速（10 rpm）转动正常
- [ ] UART 读 `DRV_STATUS`，确认无过温/过流
- [ ] StallGuard 标定：空载读 `SG_RESULT` 作为基准
