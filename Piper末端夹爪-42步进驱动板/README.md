# Piper 末端夹爪 · 42 步进驱动板

为松灵 Piper 六轴机械臂的 J6 末端自制夹爪配套的驱动板：**末端四线取电（24V + CAN），听 CAN 指令，驱动 42 步进电机推齿轮齿条**。

## 项目概览

| 项目 | 内容 |
|---|---|
| 应用 | Piper 机械臂 J6 末端夹爪（齿轮齿条，开口 20mm，m1.5 z14） |
| 末端接口 | XT30 2+2：24V / 2A + CAN_H + CAN_L |
| 板端连接器 | XT30(2+2)PB-M.G.B 板端公头（AMASS，与原厂线缆直插） |
| 电机 | 42CM04 步进（1.5A/相，保持力矩约 0.4 N·m） |
| 驱动芯片 | TMC2209-LA-T（UART 模式，1/16 细分 + 256 插值） |
| 通信 | TCAN3413，CAN 2.0B / 1Mbps（Piper 固定） |
| 主控 | ESP32 开发板（外置，2.54 排针连接，板上不含 MCU） |
| 输入保护 | PPTC + PMOS 反接 + TVS + **TPS26600 eFuse** |
| 电源变换 | LMR33630（24V→5V/3A）→ TLV75533（5V→3.3V/500mA） |
| 板尺寸 | 约 40 × 40mm，2 层 |
| 开发环境 | 嘉立创 EDA 专业版 + ESP-IDF v6.1 |

## 实现的功能

- ✅ **单线取电**：只用末端 XT30 四根线，不需要外接电源
- ✅ **四级输入保护**：PPTC / PMOS 反接 / 双向 TVS / eFuse（限流 1.46A、OVP 27.4V、UVLO 14.9V、软启动）
- ✅ **三级电源**：24V → 5V → 3.3V，FB 分压 5.02V，各级独立去耦
- ✅ **步进驱动**：1.05A RMS、StealthChop 静音、UART 可配电流/细分
- ✅ **堵转检测**：TMC2209 的 `DIAG` 已引到 J4 第 11 针，可读 StallGuard
- ✅ **CAN 收发**：1Mbps、±58V 总线耐压、PESD1CAN 保护、120Ω 跳线终端
- ✅ **默认回 ACK**：STB 下拉，ESP32 未上电时收发器仍处正常模式
- ✅ **母线电压监测**：150k/10k 分压 + RC 滤波，可发现母线跌落
- ✅ **调试支持**：4 个电源测试点 + 电源指示灯 + 11P 排针
- ⏳ **编码器闭环**：AS5600 已预留（含 I2C 上拉与 J6 引出），调试阶段不焊
- ⏳ **固件**：CAN 收帧、UART 配置、StallGuard 标定（待开发）

## CAN 协议速查

| 方向 | ID | 内容 |
|---|---|---|
| 主控 → 夹爪 | `0x159` | Byte0-3 行程 int32 ×0.001mm；Byte4-5 扭矩 int16 ×0.001N·m；Byte6 bit0 使能 / bit1 清错；Byte7 `0xAE` 设零点 |
| 夹爪 → 主控 | `0x2A8` | 行程 + 扭矩反馈（私有 ID，手册未公开） |

> `0x2A1`~`0x2A8` 是机械臂主控主动发送的反馈帧，不是夹爪发的。夹爪如何上报需实测抓包确认。

## 已知限制

| 限制 | 原因 | 应对 |
|---|---|---|
| 开环丢步 | 步进无位置反馈 | 每次张开撞机械限位回零；后期用 AS5600 闭环 |
| 无夹持力读数 | 恒流驱动，电流不携带负载信息 | 弹性夹指：力 = 弹簧刚度 × 压缩量 |
| StallGuard 静止失效 | 反电动势只在转动时存在 | 只用于"碰到即停"，不用于保持力监测 |
| 夹持力上限 25N | PETG 齿轮齿根强度 | 齿宽加到 8mm 或换 POM 材料 |
| XT30 插拔寿命 100 次 | 连接器规格 | 调试期用测试点/端子，装机才插 |

## 设计评审中发现并修正的问题

| 问题 | 后果 | 修正 |
|---|---|---|
| Q1 源漏接反 | 反接保护失效 + 启动栅极超压 | 改为 D=输入、S=输出 |
| TMC2209 缺电荷泵电容 | 电机完全不转 | 补 C18 22nF + C19 100nF |
| LMR33630 缺 FB 分压与 BOOT | 无 5V 输出 | 补 R11/R12 + C16 |
| U4 的 VIO 无去耦 | CAN 误码率上升 | 补 C17 |
| AS5600 的 I2C 未引出 | 编码器读不到 | 加 J6 |
| **EF_RTN 悬空** | **整板不上电** | 需补 0Ω 到 GND（待修） |
