# 双电机二连杆 V0：结构与实测尺寸

目标为水平桌面空载点定位。MS7015 V1（ID 2）固定在底座，驱动大臂。MS7025 V1（ID 1）装在肘部，驱动小臂。底座布局须保留 MS7015 的中心线束和浮动装置。两台在 20 V、共用 RS-485 总线下已分别完成正向 10° 位置动作，现场观察正常。MS7025 和 MS7015 的内部反馈偏差分别为 +0.02° 和 +0.01°。装臂后的表现待测。

## 布局

```text
俯视：底座 / MS7015 ● ── L1 = 100 ── ● MS7025 ── L2 = 100 ── ▼ 指针
底板固定 MS7015 机身。大臂连 MS7015 输出面与 MS7025 机身。
小臂固定在 MS7025 输出面。
```

两根转轴竖直。两轴中心距和第二轴中心到针尖的水平距离均为 100 mm。先检查 MS7025 的重量是否造成明显下垂。理想模型的半径为 0～200 mm，实际工作区由两臂高度、机身、底座、指针、线束和关节限位共同决定。装配后检查干涉范围，再选前方工作区做定位实验。

首版结构件包括底座支架、大臂、小臂和针尖夹座。底座固定在刚性底板上。大臂两端采用可单独修改的安装面，预留螺丝刀通道。臂身采用带筋截面，两臂高度按实际安装面确定。侧面八针插头预留拔插空间。根据 MS7015 中心线束实际朝向，在对应安装件留中心孔或开口槽，避开浮动件并预留插头通过和线束弯曲空间。首轮从外侧给肘关节走线，确认中心线束的电气连接和转动方式后再确定其用途。

现有厂家 MS7025 STEP 仅用来比对外形；版本没有确认。工作区原 Piper 底座的孔位不用于本机。正式孔位全部按实物核对。

## 卡尺实测表（单位 mm）

两台电机均为圆柱形，外径约 70 mm。底面为固定面，顶面为旋转输出面。建模以孔阵中心和电机轴同心为假设，孔位试装时检查。MS7015 中心浮动件平时位于内部，保留出线槽。

## 首轮试装与验收

1. 先建两台电机的外形占位和四个安装面，再建两根连杆。打印薄的孔位试装片核对对孔、定位凸台、螺丝有效旋入深度。孔位确认后再打印整臂。
2. 固定底座，先装大臂和肘电机，检查静态下垂、松动和手转阻力。若挠度或游隙明显，先加强结构或增加独立支承，再进行带臂运动。
3. 装小臂和指针，断电手动扫过计划范围，核查外壳、螺丝头、插头、线束与参考板的净空。记录无干涉的角度范围，再设软件限位。
4. 仍从单轴、小角度、低速开始。控制程序中肩关节对应 ID 2，肘关节对应 ID 1。两轴分别通过后，确定机械零位和正方向，在软件中保存偏置。
5. 在网格纸上先测三个分散的点，检查坐标方向和比例；确认一致后再扩大到整片工作区，测定位偏差与重复性。
