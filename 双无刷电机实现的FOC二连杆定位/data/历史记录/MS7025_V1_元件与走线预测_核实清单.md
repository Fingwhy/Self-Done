# MS7025 V1 驱动板功能、接线预测与核实清单

板号以实拍为准，RMD-S 70/90 V1.2.1，GYEMS。用同版 MS7015 V1 做实物对照，先确认两板装件一致。本文覆盖记录和正面照片中可辨认的器件与接口。反面、被遮挡或位号模糊的元件待补照片后逐件登记。没有原厂原理图，下面的连接按实测、同版对照和待验证推测分别标注。

## 已确认的网络

| 网络 | 实测连接或特征 |
|---|---|
| VBAT+ | 两个 V+ 互通，均直达 C1–C6 上端。 |
| GND | 两个 V− 互通，均直达 C1–C6 下端、D1 下端、U4-5。 |
| VBAT+ 对 GND | 约 5 kΩ 升至 20 kΩ。断电电阻测试未见硬短。 |
| RS485 A/B | A 直达 U4-6，B 直达 U4-7，均 0 Ω。S1 第 4 位关时 336.8 kΩ，开时 119.7 Ω。 |
| U4 VCC | U4-8 对 U4-5 稳定约 108 kΩ。芯片要求 3.3 V，实际上电电压待测。 |
| N1/N2 | 对 V+、V−、红线均未测到直连。各自去向待查。 |
| 温度探头 | 红线受热 9.82→9.21 kΩ，冷却后回升，最新 10.3 kΩ。各线对 V−、外壳均 OL。MS7015 同版接法确认 J-NTC1 是原接点。两线作为无极性 NTC，各接一个焊盘。焊接完成情况待记录。 |

## 逐区预测与核实方法

| 位号或位置 | 功能和连接预测 | 如何核实 |
|---|---|---|
| 8 针口 V+/V− | 主功率母线已实测。逻辑电源是否也由此产生待查。 | 断电从 V+ 追到稳压器输入、输入保护和中间节点。先找同版原线束及额定标记。 |
| N1、N2、外壳 G/R/T 丝印 | 可能是版本共用针位、保留位或替代串口定义。旧 70/90 另有独立控制电源，需排查本板是否存在类似入口。 | 分别测到 UART1、U2/U3 输入侧、U4 及 U5 焊盘；若没有低阻，用插座焊尾逐段追线并与 MS7015 对照。先确认外壳 G/R/T 是否对应同一排针。 |
| C1–C6 | 并联主母线储能与去耦，实测同极互通。 | 在板测得的是并联总电容及其他支路影响。逐颗容值、耐压需要料号、BOM 或隔离测量。 |
| D1 | 母线钳位 TVS、反接并联二极管或其他保护器件的候选。现已确认下端是 GND。 | 先测上端对 V+。若横跨母线，记录丝印和极性，两向二极管档与对照板比较。常规表无法确认 TVS 击穿电压。 |
| U2、U3 | U2 丝印指向 75L05 类 5 V 稳压器，先核对封装与厂家。U3 可能产生逻辑电源，5 V→3.3 V 只是候选。 | 找地脚，追两只芯片各自的输入、输出到邻近电容和 U4-8。确认料号及输入来源后，限流上电测各输入输出。 |
| L2、C13–C17 附近的电容 | L2 可能是电源串联滤波件，也可能是电感或跳线。附近电容可能是稳压输入、输出或去耦。 | 逐端测到 GND、V+、U4-8 及 U2/U3。若 L2 两端近 0 Ω，再用走线和器件外观区分磁珠、电感、零欧件。位号逐个以近照校准。 |
| U7 STM32F042K6U6 | 主控，可能连接 PWM、通信、温度 ADC、角度传感器。 | 按 ST UFQFPN32 脚图从外围焊盘追到 MCU。供电确认后查 VDD、VDDA、VDDIO2 和 NRST。 |
| X1、其两侧小电容 | 可能是外部时钟和负载电容。 | 两端追 U7 PF0/PF1，电容另一端测地。若要确认振荡，用高阻低电容探头，优先观察可用的时钟输出。 |
| S1 第 1–3 位、附近电阻 | 可能是地址选择与上下拉。第 4 位控制终端已实测。 | 断电分别拨动，测开关公共端与 GND/逻辑电源、信号端到 U7 的连接。记录原始位置并复原。地址编码等收到只读回复后再判定。 |
| U4 ADM3485E、C18 | RS‑485 收发。1=RO、2=/RE、3=DE、4=DI、5=GND、6=A、7=B、8=VCC。C18 可能是去耦。 | 追 1/4 到 U7 串口候选脚，2/3 看是否并接及是否连到方向控制 GPIO。查 C18 两端是否到 8/5。 |
| R22、D7/D8、U5、C19 | R22 标 121，可能是已测 120 Ω 终端本体。D7/D8 可能是总线保护。U5 空焊盘及 C19 可能为另一通信装配。 | S1-4 两位置下追 R22 两端到 A/B。D7/D8 逐端测 A/B、地或公共钳位节点，读顶标。U5 逐盘追供电、通信接口和 U7 后再判断可选收发器类型。 |
| R25–R28 | 记录为 R26/R28 实装，R25/R27 空置。可能是通信选装跳线或信号路由，当前保留。 | 分别记两端去向和实装阻值，对照 U4/U5、U7、插座。 |
| UART1 | 可能是板内逻辑串口。连接器针序、电平待确认。 | 先找地，再追其余针至 U7 或串联电阻。上电后示波器只接收观察空闲电平及波形，再决定接口电平。 |
| SWD1、BOOT1 | SWD 调试及启动配置候选。 | 断电找 GND，追 PA13/SWDIO、PA14/SWCLK，以及 PF11/BOOT0。确认前不跨接 BOOT1。保留原固件，功能排查先从外部只读通信开始。 |
| J-NTC1、邻近小电容及偏置电阻 | 可能是 NTC 分压输入，一盘接参考地，另一盘经滤波或串阻进 U7 ADC。 | 先测两盘对 GND 与 U7 电源轨的阻值，再追到 U7 ADC 候选脚。同版板可对照。恢复 NTC 后查锡桥，读数受板上并联网络影响。 |
| D9、R21 | D9 为灯，R21 可能是限流电阻。D9 曾在手转时短亮。 | 断电沿 D9 两端追至 R21、地或控制脚，二极管档双向比较。闪灯现象仅说明有瞬时能量到达灯支路。 |
| D10/D11 | 靠近 UART1 和母线区，可能为串口保护或供电相关二极管。 | 四个端点逐一测到 UART1、V+、V−、U2/U3 输入和附近电容。读顶标后再定功能。 |
| 左侧三个大焊盘 | 三相绕组端候选，暂编号 P1/P2/P3。 | 测三组相间电阻，扣除表笔短接值，并查对金属壳绝缘。绕组在线会把各相互相连起来，逐相网表宜结合反面走线与对照板。 |
| Q1–Q3 | AO4262E 为单颗 N 沟道 MOSFET。三颗可见管可能是三组桥臂的一侧。另一侧的器件类型、数量和位置待看反面。 | 按 AOS 数据手册核对 G/S/D，逐端量到 V+、V−、P1/P2/P3。源接 V−而漏接相端支持低侧，漏接 V+而源接相端支持高侧。绕组在线时低阻可能经其他相绕回。 |
| R4–R6 一带、C7–C9 | 重复布局，可能为栅极串阻、栅源下拉、局部去耦或开关缓冲。 | 电阻一端若到 G，另一端追向驱动器或 S。电容按端点归类，跨供电与地、跨相端与电源轨、跨栅源分别是不同候选。 |
| D4–D6、C22–C25、C29/C30 一带 | 功率区邻近重复器件，候选功能为驱动供电、自举或开关瞬态钳位。具体编号及是否重复要用近照校准。 | 先测二极管的两端和附近电容的两端。若二极管从驱动电源去浮动节点，而电容跨浮动节点与相端，支持自举。若电容跨电源轨或与相端组成 RC，则按实测改判。 |
| 反面器件、编码器及采样链 | 角度传感器可能位于靠轴心反面。接口、型号、相电流采样和电流闭环均待证。 | 补拍反面，登记磁体、芯片、分流器、放大器、驱动器和未标号器件。追供电与 SPI/PWM/模拟等接口。判断相电流采样要找到从采样元件到 MCU 的信号链。 |

## 按顺序执行

- [ ] 拍两板正反面同方向照片和芯片顶标。给大焊盘标 P1/P2/P3，J-NTC1 标甲乙，记录开关原位。
- [ ] 断电并拔通信线。轴保持静止，直流档确认母线电容接近 0 V。Ω 档短接表笔记基线。蜂鸣仅用于找低阻，记录实际值、档位、方向、是否随时间变化。
- [ ] 恢复 NTC，各线焊一个焊盘，检查锡桥和夹线。焊前可先完成 J-NTC1 的焊盘追线，避免 NTC 并联干扰。
- [ ] **优先追 U2/U3 供电入口**。从 U4-8 反追逻辑电源网，经输出电容找到稳压器，再向输入追到插座或母线。同步核对 N1/N2 到稳压器输入及 UART1。
- [ ] 验证相间电阻对称性及相端对壳。二极管档测 P1/P2/P3 各自对 V+、V−，每组换表笔方向，与 MS7015 同条件比较。持续近 0 或明显不对称时优先定位功率器件，在线读数可能经过其他桥臂及绕组。
- [ ] 取得 V1 铭牌、匹配的原配电源及线束或厂方确认，并核实是否单供电。旧 RMD-S V1.5 手册的 70/90 接法区分控制和功率电源，较新 MS7025 V3 资料列 24 V，均不足以确定此 V1 的供电方式和允许范围。
- [ ] 供电依据明确、静态异常排除后，固定电机并限流上电。记录供电端电压、静态电流、各稳压器输入输出、U4-8 对 V−，以及 U7 供电与复位。遇持续限流、异常升温或电源轨异常立即断电。
- [ ] 确认静态正常后，使用 RS‑485 接口做只读测试。老手册的试探值是 115200、8N1、ID 1，读编码器帧为 3E 90 01 00 CF。记录原始回复和轴轻转前后的角度变化。是否适用于此固件以有效回复为准。
- [ ] 最后才验证功率级输出。按已确认协议低能量空载试动，观察三相、温度及电流。高侧栅极相对自身源极测量，用合适的差分或隔离测量方案，接地式示波器的地夹不能接相端。

记录格式：板号｜测点1｜测点2｜档位及表笔方向｜开始值→稳定值｜MS7015 对照｜结论。
