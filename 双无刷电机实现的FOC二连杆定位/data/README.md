# 实测记录

position_measurements.csv 保存用户报告的定位坐标，距离误差由测量与指令相减计算。reported_trials 表示对应用户报告的试验次数，每行仍只有一个代表值。原始五次逐条坐标尚未提供。

serial_logs 保存 2026-11-11 原始工具输出。日志 utc 使用 UTC，部分文件名按运行环境时间命名。带 CSV 表头的记录包含 TX、RX、角度及事件；报告速度字段和 Output 原始字段按当时协议解释记录。

历史记录保留当时状态，可能写有尚未完成但后来已通过的检查，当前状态以项目 README 与 docs 为准。没有为缺失的实际测量补造数据。
