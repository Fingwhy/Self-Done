# 运动异常与核实清单

## 用户观察

MS7025 从静止接收位置命令后，有时以接近正常速度向目标反方向走一段，到某个角度再折返到目标。另一些时候初始方向正确，接近原速越过目标，继续走到另一角度再返回。最终位置可准确到达。用户描述为有明确路程的折返，不能用旧日志中的一次小幅反向替代整段异常的证据。

## 下一轮怎样区分原因

1. 固定大臂并使其停稳，确认观察的是小臂相对大臂角。拍视频同时保存 0x92，区分实体运动与反馈跳变。
2. 关闭 XCOM 自动循环，只发一次小角度 A4。保存之前目标、本次起点、本次完整发送帧、折返角及最终角。A4 状态应答不含原目标全文，应单独保留 TX。
3. 从相同起点、限速重复试验，对比保持上一位置闭环后直接发新目标与关闭/恢复驱动后的行为。各组明确记录 0x80 / 0x81 / 0x88 的顺序。
4. 若折返角随上次目标改变，查旧控制状态、恢复流程或命令覆盖。若总在固定实体角发生，查角度反馈及对应位置。若差异接近整圈，核对多圈绝对目标与上位机的绕圈选择。
5. 改变限速并记录速度及折返幅度。出现明显减速后越目标时，再重点比较闭环增益、负载惯量和可用制动力矩。
6. 更换一个目标、保持起点，再保持目标而更换起点，避免只凭一组轨迹归因。PID、加速度与其他设置每次只改变一项并保存原值。

## 类似公开案例

Delta Motion 的支持文章描述过静止轴受速度反馈噪声影响，在闭环切入时先反向再向目标走。该控制器的轨迹生成方式仅提供排查线索，V1 是否采用相同机制未知。

MyActuator RMD-X8 用户报告连续位置指令下停走，以及修改加减速限制后单次位置动作发生过冲。所用 V2/V3 RMD-X 固件与本机不同，参数值需按 V1 重新核实。

Panasonic MINAS A6BN 文档描述特定缓冲定位方式中先完成旧目标再执行新目标的行为。V1 是否有相似的内部状态尚未证实。

参考链接见 [资料索引](06_参考资料.md)。目前没有证据把异常明确归因为 FOC、编码器硬件损坏、PID 或齿轮间隙。
