# 接线与串口操作

## 本机电源与通信

当前使用 RXN-605D 直流输出给两台电机供电。断电接线，将电源正极接已核对的 V+ / VCC 电源端，负极接 V− / GND。两台共用 RS-485 总线，肩关节 ID 2、肘关节 ID 1。电源的市电侧按原厂接地要求连接。

以插座旁丝印为准，背面一组八针丝印从 GND 端起为 GND、GND、AUX1、B/L、A/H、AUX2、VCC、VCC。相对另一插座或从插头方向看时顺序会翻转，已购接头为 ZH1.5 8P。连接前按实测通断确认每根线，线色以当前线束核对结果为准。

本项目采用两线半双工 RS-485。T/R+、T/R− 接本机已经验证成功的 A、B 对应线，适配器 GND 与电机信号地共参考，RXD+ / RXD− 留空。适配器型号间 A/B 与 +/− 命名存在差别，不能仅按商品通用名称确定极性。已有接法应以正常回包为准。

两线红色 NTC 各接 J-NTC1 一个焊盘。N1/N2 尚未确认用途。第 4 位拨码控制约 120 Ω 终端电阻，按总线端点配置，避免各节点重复并联。

## XCOM

选择本机串口，历史为 COM10。波特率 115200、8 数据位、1 停止位、无校验。勾选十六进制发送与显示，取消发送新行及自动循环。每次发帧后查看完整回复。XCOM 与 PowerShell 串口脚本轮流使用同一串口。

| 功能 | ID 1 MS7025 | ID 2 MS7015 |
|---|---|---|
| 读编码器 | `3E 90 01 00 CF` | `3E 90 02 00 D0` |
| 读多圈角 | `3E 92 01 00 D1` | `3E 92 02 00 D2` |
| 读状态及错误 | `3E 9A 01 00 D9` | `3E 9A 02 00 DA` |
| 读速度及输出字段 | `3E 9C 01 00 DB` | `3E 9C 02 00 DC` |
| 读三相电流尝试 | `3E 9D 01 00 DC` | `3E 9D 02 00 DD` |
| 关闭驱动 | `3E 80 01 00 BF` | `3E 80 02 00 C0` |

两台 0x92 都正常，0x9D 均未取得回包。MS / RMD-S 的 0x9C 输出字段暂按有符号输出原始值保存，安培换算需要该版明确资料。

## A4 位置控制

匹配当前已验证格式的 A4 帧包含 int64 小端目标角，分辨率 0.01°，以及 uint32 小端最大速度，分辨率 0.01°/s。头部和数据部分分别使用低 8 位累加和。目标角是驱动器的多圈绝对角，需用本机上位机标定偏置换算。

生成器只打印两轴 A4，目标变化和限速可在输出中检查。应答表示设备已回复该指令，到位需要继续读取 0x92。人工复测建议先发大臂目标，观察停稳并读回后，再发小臂目标。

历史使用的 0x88 为运行/恢复相关命令，具体行为按固件而异。复现异常时完整保存 0x80、0x81、0x88、A4 的发送顺序，避免遗漏状态切换。

## 编码器实测示例

回包 `3E 90 01 06 D5 73 09 13 05 A0 0B 3F` 中，扣零后计数 2419、原始计数 1299、零点 2976。按 AS5600 的 4096 格，(1299 − 2976) × 360 / 4096 ≈ −147.39°，与 `3E 92 01 08 D9 6D C6 FF FF FF FF FF FF 2D` 一致。

多圈角由驱动器结合单圈位置跟踪，断电期间转动后的圈数保持能力尚未核实。原始编码器零点、FOC 电角度对齐零点和桌面坐标修正分别对应不同用途。
