# 运动学与坐标标定

原点为肩关节轴心，俯视向右 +X、远离操作者 +Y。q1 为大臂相对 +X 角，q2 为小臂相对大臂角，L1 = L2 = 100 mm。末端为指针尖。

```text
x 向右，+y 向前
肩关节 ID 2 ● ── L1=100 ── ● 肘关节 ID 1 ── L2=100 ── 指针
```

## 正逆运动学

```text
x = L1*cos(q1) + L2*cos(q1+q2)
y = L1*sin(q1) + L2*sin(q1+q2)
c2 = (x*x+y*y-L1*L1-L2*L2)/(2*L1*L2)
q2 = ±acos(c2)
q1 = atan2(y,x) - atan2(L2*sin(q2), L1+L2*cos(q2))
```

± 对应两种肘姿态。数学可达半径至 200 mm，原点完全折叠时大臂角不唯一，伸直与折叠附近属于奇异姿态，实体干涉和线束会进一步限制工作区。脚本提供两种解，选择需检查实物路径。

## 实物偏置

最初将照片中的伸直 +Y 姿态视为 q1=90°、q2=0°，当时驱动多圈读数为 ID 2=+32.87°、ID 1=−148.00°，得到肩参考 −57.13°、肘参考 −148.00°。两轴正方向沿用实测为 +1。保存文件为 tools/two_link_zero.json，计数单位 0.01°。

左右两个测试点偏差角分别约 +1.20° 和 +1.15°，因此加入工作区角修正 1.18°。逆解的大臂目标减 1.18°，正解使用对应的反向换算。配置在 tools/joint_angles.ps1。该值适用于本套安装，重新对准坐标轴后应复测。

这种一致的切向偏差支持固定坐标朝向偏差，具体可能包括初始 +Y 对齐、安装和肩零位标定。约 176.78 mm 半径处，1.18° 对应约 3.64 mm 切向距离。此修正的物理含义是桌面坐标与机械参考之间的旋转。
